# AccDSL research paper library

The library supports the [current governing document](../AccDSL-latest.pdf).
The initial catalogue below records 32 verified PDFs, including seven copies
from the original user collection; subsequent research adds further sources.
The [simulation-volume source record](../../data/accounting-master/simulation-monograph-20261026/source-support.json)
identifies all 26 sources cited in its new chapters, with exact retained versions,
inspected passages and qualifications. Original files remain unchanged.

Filenames use `Title First-author-surname (year).pdf`. Publication years are used when a working version underlies a later article; the actual archived version is identified below. Local copies are for research; their availability does not imply redistribution rights.

Technical reading was targeted to the claims used. See the [source-support ledger](../design/research/source-support.json) for inspected sections, allowed claims and version/correction checks. The [catalogue](../design/research/catalog.json) records URLs, hashes and extracted text paths. Citation counts are dated visibility metadata, not correctness evidence.

## Access gaps

The following important candidates have no verified primary PDF after the recorded retrieval attempts. They supply no technical support for the design:

- The REA Accounting Model: A Generalized Framework for Accounting Systems in a Shared Data Environment. (1982); catalogue ID `mccarthy1982`.
- Agent based-stock flow consistent macroeconomics: Towards a benchmark model (2016); catalogue ID `caiani2016`.
- Incomplete Information in Relational Databases (1984); catalogue ID `imielinski1984`.
- Partial Identification in Econometrics (2010); catalogue ID `tamer2010`.

See [retrieval attempts](../design/research/retrieval-attempts.json) and [omissions](../design/research/omissions.json). Rejected downloads are excluded from this library. The survey is broad but bounded; specialised actuarial, detailed standards, process-mining and multi-company equilibrium work require further module-specific review.

Regenerate this index and the bibliography from the repository root with `python3 scripts/build_design_research.py`.
