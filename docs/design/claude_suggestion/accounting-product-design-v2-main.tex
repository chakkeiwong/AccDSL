\begin{minipage}{0.9\textwidth}
This document significantly expands the v1.2 design to address identified gaps
in literature foundations, accounting coverage, industry packages, implementation
guidance, and evaluation protocols. It provides a complete architecture from
source ingestion through forecast dissemination, with worked examples spanning
non-financial corporates, banks, insurers, and specialized industries.

\textbf{Major additions from v1.2:}
\begin{itemize}
\item Paragraph-level IFRS/US GAAP/ASBE mapping framework (Chapters 14--16)
\item Complete extraction pipeline design with quality metrics (Chapter 17)
\item Expanded industry coverage: construction, extractives, software, real estate (Chapter 18)
\item Solver algorithms and optimization strategies (Chapter 19)
\item Probabilistic inference with worked examples (Chapter 20)
\item Comprehensive forecast evaluation protocol (Chapter 21)
\item Implementation roadmap with resource estimates (Chapter 22)
\end{itemize}

The core requirements, data contracts, semantics and acceptance cases continue
to govern implementation. This version adds the technical depth, standards
authority, and evaluation evidence required for production deployment.

document in \code{docs/design/research} and \code{docs/design/review}.
Gap analysis relative to v1.2 is in \code{docs/design/claude\_suggestion/gap-analysis.md}.
\end{minipage}
