# Reproduce this internal component

From this directory, use an absolute new destination:

    python3 -I -B unpack.py --destination /tmp/accdsl-new-bank-interfaces

Run the printed next_command. It writes output-01 inside the copy.
Use the recorded Python3.11/jsonschema4.26.0 environment; no installation
is performed. The driver hides GPU devices and leaves original inputs
unchanged. See README.md and result.md for comparison scope and limits.
The source materials remain internal; reproduction is not redistribution
clearance, independent domain acceptance or full runtime closure.
