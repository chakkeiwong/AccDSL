# Pre-execution review

27 October 2026. The plan passes for a separate-copy, deterministic replay of
the existing profiles. It does not pass for a merged bank accounting profile.

BankComponents/1 and /2 independently derive their financial effects from
opening states and economic events. Their verifiers do not import builders or
authored expected cases. BankAssessment/1 independently checks its supplied
US book and prudential arithmetic. The exact-time successor imports that
financial checker; it is an information-time/identity successor, not a second
financial implementation. Full saved predecessor output, with explicit reference
substitution and dependency-set ordering, is the comparator for that conversion.

The inspected module top levels load definitions and declared local imports.
Original main routines that write into frozen evidence are not invoked. Each
profile runs in a separate child process so same-named financial_checks and
source_policy modules cannot leak between AU, US and exact-time cases. The
executed module graph and all packet blobs are copied with their hashes.
The original verify.py migration writer is neither imported nor executed.

The legacy run() methods include Git/index and unrelated predecessor scans.
This is a different preservation target from recipient replay. The driver
explicitly calls their source/schema, record, independent-output, full-exchange,
crash/recovery, coverage and adversarial routines without calling historical
workspace preservation. It preserves that exclusion in the README, manifest
and results. Before/after copied-input hashes test current input immutability;
they cannot re-establish historical HEAD/index state. No check is weakened or
relabelled as equivalent.

Early diagnostic: run the exact-time component first to expose missing dynamic
imports, source paths, reference ordering or output/world drift. Then run the
three whole retained packets. A missing dependency causes a new numbered
preparation after repair; prior failed attempts remain. Child timeout is 240
seconds, an operational stop to investigate, not evidence against the method.
There are no stochastic rankings, tuning choices or installed dependencies.

The source corpus is internal. The replay preserves original historical
source claims and does not decide present regulation or redistribute materials.
The strongest misleading-success possibility is shared accounting error in
author and independent checker; original source anchors and adversaries reduce
that risk but do not replace domain acceptance. The remaining MC21 disposition
must distinguish supplied structural/method evidence from a complete integrated
same-book implementation.

Smoke-01 stopped on a missing dynamically loaded portable decoder. The import
scanner covered normal imports but missed literal file-path dependencies in
the exact-time helper's transitive input-binding module. This is a packaging
failure, not a financial mismatch. Preparation-02 adds inspected literal Python
paths to the dependency scan and retains the failed copy and log. No frozen
method or expectation changes; the same exact-time smoke remains the comparator.
