# Located annotation pilot

This packet addresses MC01–MC07, MC32 and MC33, particularly G5/G10/G11.
It prepares source-grounded proposal examples; it does not implement extraction
or establish whole-report semantic coverage. The baseline is the frozen accepted
192-report corpus and its existing annotation exchange schema.

Select Apple FY2025 Q1 inline HTML, HSBC FY2024 annual PDF, Munich Re FY2024
annual PDF and Midea FY2024 annual Chinese PDF. This purposive convenience
sample exercises manufacturing/technology, banking and insurance; US GAAP,
IFRS with local adoption and ASBE; annual/interim and HTML/PDF. It excludes
scanned/OCR-only reports and is not statistically representative. Selection and
all inspection contaminate these reports for future development/heldout splits.
Keep related issuer histories together unless a reviewed chronological protocol
explicitly defines exposure and information available at each forecast date.

Evidence contract: compare each literal, period, unit, perimeter and context
with the original retained bytes. Pass means every label resolves to its pinned
source and has reconstructible support or an explicit unresolved status. Check
PDF geometry against renders and HTML IDs against source contexts; keep support
occurrences separate from amount occurrences. Primary vetoes are wrong source
hash, wrong row/column/date, missing referenced support and unsupported assertion
of adjudication. Counts and successful schema validation are explanatory only.
No accuracy rate, extraction-tool ranking, accounting compliance, historical
byte availability or complete package coverage follows from this packet.

Skeptical audit: collection acceptance is not annotation truth. PDF extracted
text can lose punctuation, especially Munich Re's displayed thousands commas;
the visible page decides the provisional literal and the extraction difference
is recorded. Same-number facts cannot be deduplicated by value. A dash cannot
become zero without a source convention. A displayed rounded identity need not
sum exactly. A local acquisition timestamp cannot establish historical public
availability. The original source schema is preserved and new locator/time
detail is carried in a sidecar, pending architecture integration.

Audit decision: proceed with a bounded set of actual amounts and their support
spans; stop after handbook, labels, ambiguity record, verification and review.
No package installation, new source collection or product implementation.
