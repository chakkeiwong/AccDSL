# Supervisory review of the four preparation packets

The four packets supply useful proposed methods and real-source examples for
P16/P17. They remain candidate preparation. No phase, accounting framework,
product adapter, benchmark score or complete mission requirement is accepted.

The supervisor read the lease/tax dossiers, authority comparison, source
inspection notes, adapter capability matrix and evaluation protocol, diagnostic
code/results, and actual annotation records. Direct source checks included AASB
16.26/45–46/B19, AASB 112.22A/47–48/74, the official MoF single-transaction
tax case, Arelle's period accessors, Docling's XBRL output construction and
docling-core's hash conversion. Selected actual HTML facts/context/unit bytes
and seven rendered filing pages were inspected. The investigators additionally
reviewed accounting versus authority and adapter versus annotation consistency.
This is bounded internal review, not full-domain or human acceptance.

Check counts alone are not promotion evidence. |
| Native library fields could be confused with exported preservation | Pinned code shows Docling collects dimensions but omits them from XBRL value cells, retains only the first numerator unit and formats normalized boundary dates. | HTML parser output was called original markup | Adapter cross-review found normalized lowercase XML names. Root repaired markup labels to use original byte spans, original-case attributes and separate parsed attributes. Hash/locator checks and investigator reinspection pass. |
| PDF clips captured nearby rows or damaged punctuation | Root tightened numeric boxes against page geometry. Adapter review then found damaged support snippets; these now isolate undamaged headings and labels. Explicit numerical transcriptions remain tied to viewed renders, with extracted U+FFFD retained and narrowly explained. |
| A clean extraction could erase ambiguity | Distinct Apple occurrences, Midea parent/group and restated comparatives, unresolved dashes/references and Munich rounding differences survive. Publication date and historical byte vintage remain separate. |

There is no remaining material contradiction in the bounded matched examples
or source/adapter/annotation design after these repairs. A correct calculation
may still rest on the wrong real contract, tax law or applicable amendment;
these are named outstanding inputs. The method dossiers cover selected
operations, not all lease, tax, bank or insurance requirements. The four-report
pilot deliberately selects useful units and is already exposed development
data, so it provides no population accuracy or method ranking.
