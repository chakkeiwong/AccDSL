# Execute the four isolated preparation packets

User authorization: execute WORK_PACKETS.md, following the proposed parallel
preparation with outputs outside the master worktree. Packet 1 produces lease and
tax methods; packet 2 compares applicable authority on matched facts; packet 3
inspects filing adapters and designs evaluation; packet 4 labels representative
source units and defines annotation rules. These are proposed P17 inputs, not
product implementation, empirical rankings or phase acceptance.

Each investigator owns one numbered directory and must keep acquired sources,
source pins, source-inspection notes, assumptions, checks and results there. The
root agent reviews cross-packet consistency and records import decisions. Reuse
existing sources and the frozen 192-report corpus. Use legitimate official
sources; preserve unavailable authority as a claim-specific gap. No paid access,
professional engagement, package installation, model training or communication
with third parties is part of this work.

Evidence contract: compare source-defined rules and actual retained code/filings
with the proposed reading or method. Pass requires reconstructible source anchors,
explicit facts, independently checked arithmetic or located labels, and an honest
limit on unsupported claims. Missing authoritative text blocks the affected
framework conclusion; source/locator/hash failure blocks its dependent claim.
Counts, successful parsing and author-written diagnostics cannot establish source
truth, legal applicability, production correctness or statistical superiority.
No stochastic experiment is planned. Stop a packet's first investigation at its
bounded useful deliverables and report specific remaining work; no endless source
collection or proxy reporting. Research and review consume the original campaign
allowance, which is not reset.

Skeptical audit: the current corpus/proposal is the comparator, not the obsolete
manuscript alone. Lease/tax examples use declared facts and exact rational choices
only to isolate mechanics; target applicability and estimates remain separate.
Authority comparisons hold transaction facts fixed and expose framework-dependent
judgments rather than silently changing the case. Adapter source inspection does
not imply an executed adapter or benchmark. The annotation subset is purposive
and already exposed development data, not a heldout accuracy sample. Every
reference occurrence survives semantic deduplication and unknown publication
remains unknown. Label and arithmetic checks are bounded evidence, never a full
mission promotion. No architecture decision is locked by a side packet.
