# Internal work before professional review

Authority: user instruction of 2 October 2026. The quoted US$500–1,200/hour
range is the user's planning input, not a researched fee estimate. No savings
estimate, reviewer contact or expenditure is recorded.

Professional review should receive a question that internal work cannot settle,
with the relevant facts, proposed answer, competing interpretation, exact source
paragraphs and checked consequences already supplied. A request to “review the
whole design” would transfer too much avoidable preparation to the reviewer.
All eighteen audit categories still have internal work; none is presently a
reason to commission an unrestricted professional review.

After source-corpus acceptance, the [consolidated gaps and proposed
solutions](consolidated-gap-solutions-2026-10-02.md) expands the residual work,
incorporates the corpus findings and records completion evidence and order.
The agreed 192-report source panel is acquired; annotation, evaluation and
semantic package closure remain open.

## Sequence and stopping rule

Use complete bounded case annotations and expected results to drive the shared
core: remaining semantic/compiler work, bounded company execution,
temporal/review/storage tests and selected adapters. Prepare targeted
cross-standard and sector contrasts before fixing shared type assumptions.
Expand source acquisition only for demonstrated package or coverage needs,
and domain methods as each actual case requires them.
The work in this preparation pass is recorded in
[preparation results](internal-preparation-results.md); it does not replace
the remaining deliverables in the table.

Resolve cheap, discriminating questions before expanding implementation. A
missing two-line source citation does not justify a new engine. Conversely,
paying an accountant to explain an unresolved-reference error is avoidable.
Record a source-access block once; pursue a genuinely different legitimate
lead or continue independent work. Repeated failed downloads are not progress.

Before any future referral, the owner checks that the relevant source versions,
facts, calculations, alternative interpretations and document corrections are
complete; that no feasible unresolved internal task could change the question;
and that the requested judgment matters to a stated decision. Unrelated later
product work need not delay a genuinely ready, consequential narrow question.
No packet in this pass is marked ready for paid review: the cases are synthetic,
and the remaining actual-company facts/authority have not been assembled.

Ordinary reader feedback, software review, accounting judgment and actuarial
validation have different purposes. Human comprehension does not require an
accounting-firm engagement. Missing feedback retains provisional acceptance
status while internal work continues.
