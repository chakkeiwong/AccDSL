# Query-domain and resolution supplement

14 October 2026. P17-08; MC02/05/07–14/18/24–28; G1–3/G12–16/G18.
This supplements H1–H5, L2–L4 and Q1–Q3 without replacing their immutable
versions. The fixtures are authored exchange specifications, not runtime output.

## Request and result

A request names exact family, evidence view, rule, query and resolution versions;
target layer; currency/unit; economic period; scenario domain; assumptions;
operation order; input domain; output transform; explicit budget; and immutable
dependency hashes. The caller must distinguish a real principal from an integer
principal with a quantum. Display precision alone supplies neither that quantum
nor a rounding rule. Retain signed tie behavior, not just the word nearest.

For bounds, report lower/upper value, whether each is finite, whether attained,
inclusion, a witness if attained, and a proof/derivation reference. A certified
outer enclosure has a separate result kind: its endpoints need not be possible.
A rounded finite image reports the transform, discrete values/range-and-step,
coverage, witnesses and source family. It is not a new input-domain assertion.
Do not attach a nonexistent maximizer to a strict supremum.

Numeric status, existence, declared-search coverage, formulation completeness
and economic scope remain independent fields. A budget stop preserves all
unresolved regions and never proves emptiness. Complete exhaustive infeasibility
establishes emptiness only for the admitted complete formulation. Unsupported
products or unknown guards preserve the formula and affected outputs.

## Resolution and state memory

Projection equality for two histories' terminal cash is a statement about that
query. It neither proves a reusable transition quotient nor turns those histories
into one probability atom. The protected insurance case gives timely/late
terminalcash88.3, but year-one equity83 versus74.75. The bank case requires
original commitment risk/date and actual draw to measure funded allowance4;
gross loan100 is insufficient. Wrong pooled accounting is a rejected treatment,
not another admissible atom of uncertainty.

A new horizon/output/scenario/domain/method requires a new sufficiency decision.
Return RESOLUTION_REVALIDATION_REQUIRED with changed fields and preserved
constituent references. Refinement to available original data is allowed under
a new resolution; DETAIL_UNAVAILABLE reports missing detail without fabricating
history. Changed source or rule versions prevent blind search continuation;
preserve the old result as frozen and build a new dependency manifest.

when both amounts are supplied/evaluated. If the late branch is unresolved,
retain known contribution249/11 and unresolved mass8/11. A separate request

it does not answer the unconditional query. If a separately checked invariant

equality observed in another result cannot silently do so.

## Admission and implementation limits

All fixtures use exact authored assumptions and prior scoped calculations.
They are compatible with the existing shared status distinctions but do not
implement a solver, transaction engine, compression certificate or empirical
law. Broader continuous forecast protocols and cross-standard mapping remain
explicit P17-08/10/11 work. Every contract or case dependency keeps its version.
