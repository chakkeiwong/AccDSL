# Future professional review brief — unsent

This is a preparation template, not an engagement, a request for approval or
authority to incur fees. User authority to commission a reviewer and a chosen
fee/time cap are absent. Do not send this document until instructed.

## Intended scope

Commission only selected, consequential residual questions whose dependent
internal tasks in [the audit allocation](internal-before-expert.md) are closed.
The current [inventory](accounting-dossiers/inventory.md),
[bond](accounting-dossiers/compound-bond.md) and
[insurance](accounting-dossiers/insurance.md) dossiers are preparation examples.
None yet supplies a complete real fact pattern requiring a professional verdict.

For each eventual question supply a short decision sheet: jurisdiction and
reporting period, actual relevant terms and source excerpts, proposed treatment,
strongest competing reading, exact paragraph anchors, checked numerical effect,
the decision affected, remaining uncertainty, and a precise requested answer.
Attach the relevant manuscript extract and retain the full design as optional
background. Identify why internal source inspection or a counterexample could
not settle the question. Remove obsolete alternatives and repeated questions
before delivery while preserving the evidence trail locally.

## Proposed deliverables and cost controls

- A written answer for each agreed question: agree, disagree with correction,
  or indeterminate because of named missing facts/authority. Each answer should
  cite the controlling paragraphs and explain their application to the facts.
- Mark which conclusion changes a classification, journal, measurement or
  disclosure, and which is only a drafting preference. Supply a corrected
  example only where the agreed question requires one.
- Agree a fixed fee or capped hours for that exact packet before work begins.
  The user chooses the cap; this template invents no “optimal” review duration.
  Prefer a focused written response before considering a meeting.
- If missing inputs, additional questions or an approaching cap would expand
  scope, stop that portion and return a concise clarification/change request.
  No open-ended whole-document rewrite, source collection or software debugging
  is included in the proposed scope.
- A second review, if needed, covers the changed treatment and its dependencies;
  it should not repeat completed preparation or unaffected issues by default.

These terms would require the reviewer's agreement in a real engagement. They
are not a claim that a professional firm has accepted them or that all
professional review can safely be eliminated.

## Separate acceptance records

Keep professional accounting conclusions distinct from software conformance,
human reader comprehension, actuarial estimation and empirical forecasting
evidence. An accounting sign-off cannot certify the compiler; passing software
checks cannot establish an actual instrument's accounting classification.
The user-supplied US$500–1,200 hourly range motivates preparation but does not
quantify savings. Record actual agreed scope and cost only if an engagement
is later authorised.
