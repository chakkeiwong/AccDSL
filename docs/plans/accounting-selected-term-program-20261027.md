# Complete selected-term program execution contract

27 October 2026. MC11/13/16/18/24/25/28/33/34; W11/12/16. Follows the
acceptance and compatibility audits. Candidate 5.51 remains unchanged.

Research/engineering intent: can the existing source term executor compose an
ordered program while preserving exact selected identities, supplied population
coverage, full state and the first refused prefix without historical test-harness
or native financial callbacks? Candidate: a bounded typed program envelope,
not a new accounting algorithm. Comparator: the two preserved ten-command full
source-result traces and independent final cash/claim/book identities already
recorded there. The old writers must not run.

Before implementation check actual execute_sources consumers for an existing
equivalent. Pass requires exact equality of every complete source execution
result in both traces, propagated coverage across periods, the same final states,
explicit no-op/partial/refused distinctions and meaningful source, identity,
request-order, state, unknown-input and carry controls. Native financial/lifecycle
builders remain disabled. A prefix mismatch, dropped command, fabricated
coverage/selection, mutated input or lost zero vetoes this increment and triggers
repair. A refused candidate command is expected evidence, not a global stop.

Default/assumption audit: maximum 64 commands is a defensive profile limit, not
a capacity claim. The two synthetic charts and selected date-only carry policy
come from frozen examples; no actual company completeness or accounting authority
is inferred. The caller supplies reviewed source/opening/coverage/command
identities independently; the runner cannot bless modified source by generating
its own selection. It may derive transport call hashes after verifying that
selection. A request's expected-state hash remains supplied and must match the
current state. Returned coverage is carried forward, never rebuilt as complete
by inspecting a book. No arbitrary report command: the declared carry's existing
complete report request/result is preserved; broader reporting stays explicit.

Contract: validate the closed envelope and all identities before starting;
execute the ordered commands using exact selected sources; preserve complete
results and state/coverage after each success; stop at first refusal with failed
command index, exact successful prefix and untouched remaining requests. A
source/structural defect refuses before execution. Runtime status remains the
underlying exact status, accompanied by a program status. No commit or durable
store is implied. Independent final-state assertions supplement inherited
oracle equality, which alone cannot exclude shared implementation defects.

Use a fresh data/accounting-master/selected-term-program-20261027/attempt-NN
directory, preserve source hashes, commands/environment/time, controls and exact
result traces. First run only the two bounded traces and targeted adverse cases;
no statistical ranking, performance benchmark or research-method promotion.
After checks pass record the interface and update the live master. Continue
the modern dependency bundle and remaining C2/C4 work; do not manufacture a new
manuscript version for operational status.
