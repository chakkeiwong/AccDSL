## Skeptical audit and evidence contract

The wrong baseline would be installed Arelle or a generic RFC URI resolver.
Neither is evaluated here. The retained graph used its own documented URL/base
rules. Pinned source uses path normalization, mapping precedence, cache fallback,
plugin hooks and a distinct xml:base algorithm. Static graph closure cannot
establish native loader equivalence or zero network access. An empty plugin or
package request cannot certify effective process state without later evidence.

Audit passes for a documentary receipt specification and finite consistency
check. Record any unsupported URI forms explicitly, including their effects on
the next action. A missing prerequisite holds runtime promotion, not continued
specification or unrelated source work. Avoid manufacturing exact package pins
from version ranges or the current tfgpu environment.
