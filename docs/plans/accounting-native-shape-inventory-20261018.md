18 October 2026. P16/P17/R06; MC01–06/23–25/27/28/30–35.

## Question and skeptical plan audit

Which structures in the protected Apple native instance remain outside the
twelve-fact portable example, and what must a broader documentary translation
preserve or leave unresolved? Compare the exact retained instance with the
selected-portable conversion contract; do not use selected success as evidence
of whole-filing coverage. The prior totals (1,127 facts, 193 contexts, seven
units) are reconciliation baselines, not a license to discard other root nodes.

Audit passes for a source-only inventory. Retain every top-level element,
including references and links, with original byte spans and attributes. Use
Expat byte positions plus independently parsed ElementTree fragments, not
serialization offsets. Before interpreting numeric strings, distinguish lexical
rational candidacy, unit presence and unknown taxonomy typing. Missing/duplicate
IDs, unmatched joins, repeated facts, child content, context qualifiers and
namespace scope are explicit hazards. No selection, accounting or runtime
compatibility is promoted from these counts.

## Defaults and assumptions

Use the retained UTF-8/CRLF native instance only (baseline with pinned hash).
Reject DTD/entity declarations, CDATA and local namespace redeclarations unless
explicitly supported after review. Both source decoders must agree. The default
namespace applies to unprefixed source QNames; source dates remain tokens.
Fact classes are lexical hypotheses only: nil, exact rational token, text, or
child content; a monetary-looking string alone does not establish its XBRL type.
Repeated concept/context/unit/text signatures retain all occurrence IDs, even
when numerically or textually equal. No rounding, sign policy or deduplication.

No stochastic comparison, new dependency, source download, numerical framework,
GPU, upstream execution, manuscript edit or empirical campaign. Run standard-
library checks with bounded summaries in existing tfgpu Python. Protect existing
source/types/evidence, manuscript, Git index and unrelated dirty work.

## Sequence and result decisions

1. Implement a finite exact-source inventory with independent fragment checking.
2. Classify every structural hazard and distinguish representable, requiring
   adjunct, or unknown admission. Exercise intentional omission/span/join/class
   corruptions; record the selected negative cases before execution.
3. Record once, replay read-only, write the result and additive R08 supplement.
4. Refresh the master to the next concrete repair justified by the inventory.

Potential misleading pass: an inventory can account for all XML occurrences
while missing economic meaning. Keep that distinction explicit. Expected novel
structures trigger representation repair, not a global continuation veto.
