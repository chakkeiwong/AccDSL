# Audit repeated conditional native events without witness substitution

24 October 2026. S2–S4; MC04/05/08/09/10/11/13/16/24/26/28/35.

Inspect the new one-opening conditional return family and native settlement/sale
transition to identify the smallest faithful sequential extension. Main question:
can uncertain settlement carrying values pass into later sale cost and cash
constraints without selecting a single intermediate state? Comparator: original
native transition sequence on every complete event assignment.

Skeptical audit: the one-event interface accepts a complete concrete state. Feeding
its first witness to the next call would discard other valid states. Re-running
the same next-event domain independently also destroys shared carrying-cost
dependence. These are target mismatches, not evidence that sequential uncertainty
is impossible. Do not describe a list of representative paths as a complete
family, or attach weights from the number of witnesses.

Inspect which fields change after settlement (cash, inventory, rights, lot
carrying/units/tax base, tax adjustments and seen/flows), which later sale reads,
and the exact chronological/identity rules. Write dependency and assumption
tables before probes. Compare two retained settlement branches followed by the
same sale; determine whether an explicit complete two-event symbolic family can
retain both with the existing piecewise/linear primitives. Fixed source facts,
identity topology and one known opening remain the initial fragment.

Evidence contract: exact positive and counterexample probes distinguish common
closing cash from differing profit/carrying cost, demonstrate loss from an
arbitrary intermediate witness, and retain all original state validity checks.
No new numerical solver, stochastic comparison or production default. Missing
structural state, nonlinear products or an unaccounted native check blocks that
proposed extension and triggers a revised explicit scope, not guessed facts.
