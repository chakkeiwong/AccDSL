# R03-H — financing conditions and excluded hedge components

15 October 2026. Protected baseline Version 3.04. Documentary work under
MC13/16/19/20/24–28/30/32–35; no runtime or empirical execution.

## Question and skeptical audit

Can the financing design determine recognition when conversion terms change,
hedge components are excluded or the hedge ratio changes, and awards have
different vesting/settlement conditions? The comparator is the existing
immediate unconditional conversion and whole-derivative hedge method, not an
invented implementation or weak numerical baseline.

Audit before execution: an amendment-date valuation is not automatically a
recognition-date answer for a contingent obligation. Excluded option time
value is not hedge ineffectiveness by default. Rebalancing changes quantities
prospectively after measuring existing ineffectiveness; it must not erase
past reserve history or disguise a changed risk-management objective. Equity
classification and EPS inclusion are separate tests. A paper-only illustration
must not be promoted into a valuation engine or cross-GAAP rule.

The safe first unit is source-supported excluded-component and rebalancing
methods with exact supplied-value examples. Examine inducement timing and award
conditions independently; retain a named source/interpretation gap if the
inspected authority cannot resolve it. This is a method-repair boundary, not
permission to call the full financing profile complete.

## Evidence contract and sequence

1. Inspect retained AASB9 6.5.5–6.5.6, 6.5.15–6.5.16 and B6.5 guidance,
   plus relevant IAS32/IFRS2/IAS33 clauses for the remaining branches.
2. State records, recognition ordering, same/different critical-term handling,
   basis/reclassification treatment and failure behavior. Keep valuation inputs
   explicit and preserve the risk-management objective and designation history.
3. Check the smallest exact examples that distinguish these methods from the
   whole-derivative baseline. Archive source clauses and all assumptions.
4. Integrate a protected successor, verify preserved mathematics/citations,
   build, inspect affected pages and refresh remaining dependencies.

Pass requires a source-grounded conditional procedure and independent exact
reconciliation. Wrong recognition timing, omitted cash/equity movements or
allocation target veto the case and trigger repair. A missing authority blocks
its claim, not the independent ready methods. Counts and successful builds are
engineering checks only. No ranking, calibration, current-law certification or
empirical effectiveness is inferred.

Assumptions to audit: source edition/jurisdiction (historical baseline), supplied
fair values (illustrative inputs), aligned critical terms (conditional case),
linear period allocation where used (declared policy requiring rational basis),
and exact arithmetic (checking tool, not runtime selection). Earliest diagnostic
is a journal-and-reserve reconciliation that fails if excluded time value is
mixed with designated intrinsic value. Missing real facts block application.
