## Skeptical audit and evidence contract

Audit passes for local source correspondence only. An ElementTree
reserialization cannot establish original bytes; locate unique lexical start/end
tags in the retained UTF-8 file and independently compare parsed fragments to
the full parsed element using its unique ID and position. Scope the locator to
this retained file: no generic XML parser, arbitrary encoding, CDATA, mixed-tag
locator or Arelle parity claim. Verify assumptions before any output.
