Question: when only declared message labels change, can every total joint-stage
policy assignment and refusal witness be transported exactly while preserving

renamed declaration using the same checked source frontier. Start with exact
renaming; observation refinement requires a separate relation and is not
silently included. Keep the established single-date transport as background

relabelled as current without checking the domain relation and rebuilding the
result's bound identities and witnesses. A collapsed map is outside the exact
renaming relation. Refuse changed dates, budgets, raw keys, source bindings or
financial content. Preserve pending, unknown and inconsistent states.

validated refusal witnesses and unchanged source support are primary. Compare
fresh target results at root, a nonempty partial prefix and complete endpoint
