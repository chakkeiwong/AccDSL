The audit passes with these limits: bibliographic completeness is not source

erratum status is not evidence of an error or retraction; a failed old URL is
not proof that full text is unavailable; a bounded exact example is not
forecast validation. Use a new repository or author route before repeating
exhausted downloads. Do not compare a finite-history compatibility set with a
statistical identified set without the required observation model.

## Evidence contract and defaults

Comparator: the existing 26-source support map, Chapter 19 and the current
S1 remaining-work record. Primary criterion: each material gap has an exact
local anchor, consequence, source or method to investigate, and closure test.
Vetoes: fabricated references, uninspected technical claims, lost source bytes,
unrecorded version mismatches, or overwritten concurrent controls.
Source counts, search-result counts and download success are explanatory only.
No claim of exhaustive literature, correct general simulator, calibrated
probabilities or method superiority follows.

Priorities are engineering judgments based on consequences for state,
information and financing semantics, not citation counts. The existing
synthetic cases are teaching examples; any new examples here must be labelled
as proposed checks unless executed. Correction notices are checked through
specific public sources; absence from one source is only a limited negative
finding. No fees, professional outreach, solver adoption or long experiments.

## Sequence

1. Separate named source blockers from substantive method and validation gaps.
2. Retrieve a small set of new primary-source leads and preserve provenance.
3. Inspect enough technical text to decide the proper reading priority,
   without upgrading discovery into implementation support.
4. Record gap-specific closure tests, dependencies and proposed counterexamples.
5. Verify local links, retained source hashes and honest current statuses.

The result must explain what can be closed internally now, what needs
institutional access if public routes fail, and what requires derivation or
data rather than another citation. No source gap is closed by changing its
label alone.
