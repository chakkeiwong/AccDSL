## Completion and continuation rules

Each unit must end in one of: a checked scoped deliverable, a precise
source/fact blocker with its affected claim, or a finding that requires a named
repair. An inaccessible/private fact remains unknown; retain alternatives and
their conditional consequences instead of inventing a value. An unknown can
be legitimate design content, but a missing required method or worked case
cannot be relabelled an implementation task to obtain readiness.

After finishing or blocking a unit, continue the next independent ready unit.
Repeat a failed source route only when new evidence supports a changed route.
Pause dependent work for corrupted inputs, conflicting writes, an invalid
mathematical target or an actual permission/cost boundary. Routine plan,
calculation and prose repairs require no new permission. External messaging,
fees and publication have no authorization here.

The stop condition for the proposal stage is an exact, internally review-ready
candidate with all required design evidence and no unresolved consequential
design decisions. Independent review then assesses technical proposal readiness;
required human/domain judgments remain separate and block final acceptance
until resolved. If required evidence is
still unavailable after feasible internal work, record **not_ready** and the
specific blocker. Never convert a source count, plan coverage or author
integrity check into positive readiness.

P00–P14 remain the held implementation/evaluation program: source preparation,
lowering, reconstruction, execution, time/review/persistence, corporate and
sector engines, adapters, benchmarks and forecasting. Some bounded work
already exists. Before later execution, reconcile it with the finished
proposal and refresh its implementation plans. Passing P19 does not start it.

## Skeptical audit and preservation

The planning audit found stale execution pointers, historical campaign
deadlines in otherwise useful plans, incomplete SQL closeout, and residual
descriptions that mix design and runtime evidence. The revised plans repair
those defects without narrowing scope. They explicitly reject four weak
substitutes: successful download for source support, correct local arithmetic
for general methods, PDF build for comprehension, and a populated assessment
for readiness. Historical paper/current-authority mismatches, private company
facts and undocumented numerical defaults remain named risks.

Planning review passes for direct internal continuation. Each later research
run still needs its own actual target, environment, budget, diagnostics and
stop conditions. No benchmark, implementation launch or source-acquisition
campaign was run by this planning refresh. The
[audit record](../../data/accounting-master/remaining-phases-audit-20261014/review.md)
records findings, prior controls and verification. The protected manuscript,
