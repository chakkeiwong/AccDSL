identities. The 5.9.0 witness is a convenience research boundary, never a
selected runtime default. Do not download or execute build machinery; read its
code and terms statically. If the witness exposes no usable native identity,
record that limit rather than guessing the latest PDFium build. Audit passes
for this bounded documentary inquiry; there is no performance comparison.
