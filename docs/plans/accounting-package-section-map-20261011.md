# JPMorgan omitted-section mapping

11 October 2026. E01/MC01/03/05/28/30/33–35; G5/G11/G13/G18. Question: which
document sections omitted from the selected 2022–2025 annual-report counterparts
are present in the complete issuer 10-K candidates, and what source boundary
remains? Baseline: closed three-role package ledger (26 checks, 1965-file
manifest), retained annual reports, complete 10-K PDFs and filing events.

Primary criterion: for each year, retain selected/complete PDF page counts,
the exact exclusion notice, complete-candidate section anchors and a bounded
statement that the candidate contains the omitted page ranges. A page-count or
string match is only a structural source diagnostic. Promotion vetoes: wrong
year/form/issuer, absent complete page range, invalid extraction or replacing
the original annual report. No semantic annotation, note cross-reference,
incorporated-document closure, byte equivalence or accounting conclusion.

Skeptical audit: PDF page numbers and printed filing page numbers can differ;
the annual report may use a separate pagination and include sections outside
the filed form. Use complete PDF page positions plus printed table-of-contents
and heading evidence. Do not claim that presence of Item 1A or an ending
signature establishes every omitted disclosure. Preserve source roles and all
clocks. A four-row map cannot close whole-company package semantics.

Use only local retained PDFs/text. No network, installation, extraction of new
documents or manuscript build. Verify 1965 inherited references and four live
controls, run bounded page/text diagnostics, record exact excerpts and limits,
update controls and continue feasible internal work. Do not rewrite frozen
corpus or release manifests.
