# R06 — Full retained-native documentary portable translation

18 October 2026. P16/P17/R06; MC01–06/23–25/27/28/30–35.

## Question and skeptical audit

Can every inventoried top-level source occurrence in the protected Apple
instance enter the existing proposed portable representation without losing
source identity, typed subtrees, lexical tokens, repeats or unresolved meaning?
Baseline: the 1,328-element checked structural inventory plus selected-portable
and hazard-portable finite examples. No new source, taxonomy or runtime is used.

Audit passes for documentary correspondence. Full XML occurrence coverage is
not full report semantics or financial admission. The existing inventory
establishes 1,127 fact occurrences, 193 contexts, seven units and schemaRef.
Preserve all, including 69 repeated-signature groups. Do not simply apply the
twelve-fact numeric choices to other concepts: use a stated lexical policy,
keep candidate status and preserve taxonomy type Unknown in the packet.
The full-file run is a deterministic specification check, not an empirical
campaign or product runtime. No controller, installed importer or dependency
installation is authorised by this plan.

## Evidence contract, assumptions and pre-mortem

| Role | Requirement |
| --- | --- |
| Question/mechanism | Existing body types plus checked source-link adjunct preserve all inventoried source occurrences |
| Primary pass | Exact complete selection, original byte/tree/text joins, typed closed Refs, source-period/unit/dimension preservation, candidate values and total per-owner field mappings |
| Promotion veto | Missing/merged occurrence, lost typed subtree/unit side, normalized identifier, nil-to-zero, unsupported source type/time/language, changed schema, source/packet conflation or absent field provenance |
| Continuation veto | Protected source corruption, original-byte disagreement, invalid packet or resource demand exceeding bounded local checks |
| Repair trigger | Unsupported source structure or misleading candidate policy: preserve evidence, revise the specific mapping before recording |
| Explanatory only | Counts, wall time and repeated signatures; no extraction accuracy or performance claim |
| Non-conclusions | Taxonomy/XBRL validity, accounting admission, resolved schemaRef, historical availability, installed Arelle behavior, complete economic disclosure or forecast validity |
| Artifact | native-full-portable-20261018 packet, records, adjunct, checks, manifest, result and additive R08 supplement |

Material defaults, provenance and early checks:

- Full fixed selection comes from the checked inventory, not a convenience
  subset. Reconcile every category/ID and original locator before translation.
- The 961 unit-bearing decimal-looking strings become exact Decimal candidates
  without scaling by decimals; this is a lexical hypothesis, not admitted
  taxonomy typing. Independently compare source Fraction and preserved token.
- Two source nils remain Nil with no rational; seven unitless digit strings
  remain Unknown Values and retain exact characters (including CIK zeros).
- The other 157 strings use a packet UnvalidatedText tag, explicitly converted
  to portable Text through a dedicated method. This means a character container,
  not taxonomy or sanitized text. All 56 markup-like strings remain verbatim.
- Typed members retain original subtrees/spans and Unknown member_qname; source
  periods remain evidence while every financial-time field stays Unknown.
- ID-less schemaRef uses null source ID and the unchanged proposed link adjunct.
- Reuse frozen profile/primitives without editing them. Current Python/tfgpu is
  a convenience environment: standard-library CPU checks only, no frameworks/GPU.

The chief misleading-pass risk is shared construction/checker logic. Check
source fragments/joins/value tokens independently against original XML, fixed
inventory counts and targeted corruptions with re-bound dependent Refs. Exact
reconstruction is only additional regression evidence. Bound output to counts,
IDs of failed checks and artifact paths; never print the full record packet.

## Sequence and stop conditions

Prepare full packet; implement explicitly scoped successor constructor; validate
all records/mappings and representative semantic corruptions; record once and
read-only replay; write result/manifest; bind R08; refresh master next work.
Use one writer, preserve prior evidence and the 36-entry tracked dirty set/index.
No manuscript build, upstream execution, benchmark, install, commit, publication,
outreach or fee. Failed examples trigger repair; no global veto has fired.
