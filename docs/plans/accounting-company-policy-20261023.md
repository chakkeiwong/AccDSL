# Explicit settlement policy versus fixed allocations

and company-information drafts. The current policy work is optional; it cannot
replace or reinterpret saved fixed-settlement outcomes.

## Skeptical audit and research intent

Question: when an invoice amount changes, can an explicitly authored settlement
policy generate a new named claim allocation without silently changing fixed
cash instructions or unrelated claims? The exact baseline is the 2026
price-11 path and its named 396/5 collection for each newly issued 176 receivable.
The fixed-allocation comparator changes price to12 while preserving both
396/5 settlements. The candidate policy recomputes 90% of each revised 192
receivable, or 432/5, at the same named collection operations. The 90% rule is
retained from the earlier illustrative annual profile only as a test hypothesis;
it is not estimated payment behavior or a product default.

Promotion criterion: local replay validates both paths; only the four targeted
allocations within two collection operations change; each remains within its claim; generated settlements plus
remaining receivables equal the invoice amount; revenue, cost and profit remain
equal between the two price-12 alternatives; cash increases and receivables
decrease by the same generated-versus-fixed difference. Existing settlements
for older claims, dates and operation identities remain exact.

Promotion vetoes: changed fixed path, mismatched claim or operation ID, implicit
rounding, over-settlement, duplicate policy target, missing remainder,
unbalanced statements or policy code loaded from the packet. Any accounting
implementation mismatch is a continuation veto for this candidate until
understood. An authored fraction's poor realism blocks empirical interpretation
but does not invalidate deterministic conformance. Speed and check counts are
explanatory only.

The run must distinguish a policy-generated conditional path from the fixed
input path and bind the policy, parent input, materialized input and result.
Assumption-information admission for the policy itself is a separate residual;
path timing does not timestamp this policy automatically.

Passing would show only deterministic implementation of this declared schedule
on a synthetic company path. It would not show that the schedule is realistic,
causal, tax-appropriate, generally optimal or predictive. No future-date
assessment or candidate ranking is permitted.
