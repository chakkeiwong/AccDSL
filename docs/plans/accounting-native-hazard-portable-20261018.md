## Execution and failure handling

Prepare source packet from checked inventory; preserve exact input hashes.
Create additive typed examples and source-link evidence. Check independent XML
subtrees/joins, reference closure, every mapped field and semantic corruptions
with rebuilt dependent Refs. Record once and replay, bind R08, then refresh the
next task. A rejected corrupted example is a passed screen, not rejection of
the representation direction. Broader translation follows only after these
specific source structures have explicit dispositions.
