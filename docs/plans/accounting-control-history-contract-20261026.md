## Inspected interfaces and bounded execution contract

CompanyWorldEnvelope/1 uses start/end_exclusive control edges with an explicit
control_premise; it does not validate continuous source coverage. Its duplicate
parent/child-pair rule also does not express repeated control spells. The finite
vintage selector preserves source hashes, supersession and actor-specific
availability; unknown availability is unresolved, not future. Reuse the existing
ExactInstantProjection/1 instant parser and its exact fixed-offset time axis.
No new core world or clock version is introduced by this companion.

Selected schema: a supplied source record asserts yes/no/unknown control over
an explicit half-open effective interval, with a required whole-interval
interpretation, subject/basis, immutable content hash, evidence hash, actor
availability and optional superseded record. A revision must retain the same
subject and interval. This restricted rule avoids inventing partial replacement
semantics; partial revisions require separate intervals in a future extension.
There is no inference from an empty event list or two matching snapshots.

For a query interval, split at every eligible source boundary and preserve each
atom. One consistent known status may support an atom conditionally; no source,
unknown status, conflicting statuses or unknown actor availability leaves the
atom unresolved. A future record cannot change an earlier query. Supersession
uses only available descendant records; malformed identities/ancestry refuse.
Same instant is a shared boundary, not an invented order. Distinct offsets that
denote the same instant must behave identically. Output never authorizes world
control edges, journals, source truth or accounting admission.

Pass criteria: complete atom partitions equal independently authored examples;
known/unknown/conflicting/gap dispositions correct; old and corrected actor
views remain separate; exact boundary and offset cases agree. Compare a small
two-cell three-state family with exhaustive expected cell dispositions and
refuse malformed identities, intervals, revisions and timestamps. Retain future
exclusions and all unresolved obligations. Engine agreement and test counts do
not prove actual evidence completeness or establish a full temporal logic.

Audit passes: the interval-coverage premise is explicit and source-labelled,
unknowns and contradictions remain visible, one immutable exact-time parser is
reused, and conditional completeness cannot be confused with source admission.
Three60second CPU attempts remain the budget. No journals or common core edits.
