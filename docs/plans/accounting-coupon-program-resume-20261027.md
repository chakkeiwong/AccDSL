# Resume selected same-period coupon instructions from a verified prefix

27 October 2026. MC05/11/12/13/16/17/18/24/25/26/28/33/34;
W04/05/11/12/16/17. This repairs the specific interface gap exposed by the
continuation-scope companion. It remains selected design/conformance evidence.

Research intent: can a bounded runner process a supplied multi-event suffix in
chunks without resetting its original reporting opening or changing which
events are accepted? Compare uninterrupted selected typed execution with chunked
resume and an independent full-state oracle. Preserve exact failed instruction,
remaining commands, original refusal and all accepted prefix history.

Skeptical audit: restarting DeclaredCompanyProgram/2 from a midperiod book is
wrong for its fiscal-opening contract. Do not edit that frozen runtime or call
a direct step a general program. Define SelectedCouponProgramResume/1 with an
immutable source/selection, original period opening, verified initial prefix,
full supplied suffix and a cursor. Bind every checkpoint to that entire plan.
One chunk size is an execution convenience, not a financial assumption.

No callback or invented accounting mechanism: use the existing typed event
engine. Keep the complete cumulative report anchored to the original opening.
An initial prefix must pass the independent prior full-state checker. A resumed
checkpoint must be validated against the immutable plan and exact accepted
prefix, not trusted because the caller supplies its hash. Snapshot verification
may recompute already declared transitions for validation; it must not publish
duplicate accepted events or duplicate flows. This is pure replay, not durable
exactly-once execution or storage authenticity.

Limits: one plan contains at most 64 suffix commands, with the same 8 MiB trace
ceiling inherited from the prior runner. Chunking cannot reset these budgets.
Return complete, paused-by-budget, refused, or resource-limited states with
explicit cursor and remaining commands. A refused or resource-limited command
is never skipped on resume; changing a command requires a newly identified plan.
Report, carry, cross-period and other method families are outside this selected
event-only contract. The underlying engine still enforces dates, IDs and numeric
limits. Wrong source, registry, opening, prefix, cursor or trace must fail.

Default/assumption audit: synthetic partial-coupon semantics and classification
are frozen; exact fractions avoid tolerances; chunk limits 1/2/all are convenience
test splits. Stop conditions are explicit. Recompute-and-compare is acceptable
only as bounded conformance, not a claim of scalable or durable recovery. Early
diagnostic: one interrupted successful schedule must equal the uninterrupted
complete state, trace and cumulative report before the broader case table.

Predeclared cases on four chart/action origins: a three-event positive suffix;
a later unaffordable payment; duplicate ID; backwards date. Compare all splits
1/2/all, including refusal exactly at a chunk boundary. Test stale origin,
selection, opening, changed suffix, skipped failed cursor, removed trace, lost
history, falsified report/admission, and a 65-command plan. Explicitly check that
budget pause differs from economic refusal and that terminal resume is unchanged.
Source drift, comparator disagreement or hidden skipped events veto promotion.
Local defects trigger repair; invalid upstream evidence or three exhausted
120-second attempts stop this unit, leaving independent packages available.
