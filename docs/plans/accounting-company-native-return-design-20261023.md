## Skeptical audit and evidence contract

Do not add a return journal as an isolated post-processing adjustment. The
native company model currently fixes inventory to units times one unit cost,
omits refund/recovery balances, closes a fixed temporary-account set, computes
tax as immediate book-profit deduction and exports fixed annual memory and
29 report lines. A return with recovered cost 20 for two units violates the
old inventory convention when its homogeneous unit cost differs. A completed
tax report would be unsupported without explicit tax-base/timing evidence.

First specify module-owned component memory and a separate recovered inventory
lot, shared book account registration, journal/event ordering, gross cash,
unknown/failure propagation and later-year carry. Retain the homogeneous legacy
lot unchanged. Define exact tax facts/temporary differences or leave the
affected close unresolved; do not inherit immediate_deductible as a new default.
Preserve entity, dates and source profiles. Keep instantiation under newly
authored synthetic premises separate from migration of a historical owner.

Use the retained CompanyComposition legal-book case and its source-specific
return/tax derivation as the baseline. Inspect technical primary-source anchors
before making any additional accounting claim. The first useful artifact is
a dependency-complete native extension specification and a matched trace of
opening balances, return settlement, recovered sale, current/deferred tax,
cash flow and closing memory. Existing group adjustments need not be invented
again; reuse their preserved legal-book decomposition.

Primary criterion: every changed state and statement quantity has a checked
source, explicit premise or derived formula; whole conditional legal-book
results match the retained comparator; all original scenarios remain unchanged
through an explicit legacy mode. Missing findings, owner changes, unbalanced
or double-posted effects and a tax close without complete inputs veto promotion.
Coverage counts and successful compilation are explanatory only. Missing
indispensable source/comparator bytes halt that dependent claim; other design
work continues. Rejection of a convenient join triggers the planned repair.

Defaults: recovered lots retain exact historical carrying values; source
findings are supplied synthetic premises, not real company evidence; date and
cash classification follow the retained case; a tax rate is a case input, not
a universal rule. Test the old unit-cost invariant and opening tax differences
first, before writing native engine code. No experiment or probability is
introduced. Save the design and finite exact checks under
data/accounting-master/company-native-return-design-20261023. Integrate the
coherent portable/module/native design group into a protected manuscript
successor only after its governing semantics are settled. S6 remains held.
