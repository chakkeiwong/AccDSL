piecewise monetary family to the selected native method's numerical prerequisites,
without inventing source facts, eligibility or memory state? Inspect the current

Skeptical audit: monetary balance is not native feasibility. Do not assume that
unit domains imply quantity caps, rights, chronology or whole-lot disposition.

different meanings. Check exact cross-profile contexts, scales, input identity
and source hashes before proposing any join. Existing guard semantics and status

a numerical system has a witness.

Evidence contract: inventory the complete selected native prerequisite inputs,
predicates, guards, roles and provenance; map every dependency to method input,
known fixed fact or unresolved external obligation. Preserve unmapped dependencies.

to existing affine branches and which need separate support. Primary pass is exact
dependency accounting and faithful comparator classification, not count or speed.

audit and trigger repair. Missing actual issuer facts do not block the audit.

comparator. No company facts are inferred. Typed contexts are preserved explicitly;
any mapping is a declared checked proposal. No new solver or native execution.
CPU-only bounded probes; no experiments supporting an economic or statistical
claim. Record source locks, audit/result and a separately audited implementation
plan under data/accounting-master/method-family-prerequisites-audit-20261024/.
