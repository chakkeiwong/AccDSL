references can be resolved into reviewable repository identities, file

whose repository names and tags do not establish exact assets. The candidate

Skeptical audit: resolving `main` today cannot recover the assets selected by a
past install. Call it a present inspection candidate, not a historical lock or
recommended version. Repository metadata may expose LFS hashes without the
weight bytes, which remain unverified. Model cards can contain broader licence
assertions than a subdirectory notice; inspect both. Audit passes under these
source-only limits. The preceding 1441 references and four live controls must
verify before acquisition.

Defaults/assumptions: use only repositories and revisions established by the
previous source call path; this is provenance, not model selection. Limit small
text/metadata responses to 1 MB and 45 seconds, at most 14 distinct URLs, and no
automatic retries. A confirmed sandbox network failure may receive one trusted
retry; a failed trusted route needs a genuinely new source lead. Paths for
licence/card/config acquisition must come from the returned file inventory.
Do not fetch weights even if small. Do not install/import model libraries.

Execution: verify/preserve the prior state; query official model metadata for
the two revisions; inspect returned file names; fetch bounded relevant small
text at the resolved commits; read full terms and model descriptions relevant
to use and limitations; distinguish upstream declarations from local judgments.
Record source checks, decision/inference status and remaining package/loader
obligations. Retain Version 2.26 unless a material reader-facing omission is
found. Close coherently, then continue exact TableFormer package preparation or
another feasible queue. Missing human acceptance is not a continuation veto.

Pre-mortem: a repository card marked permissive might omit third-party assets,
or the bundle could contain unrelated models. Inventory scopes and hash fields
must remain attached to exact filenames; no top-level label clears a bundle.

## Terms-source refinement

The retained model cards declare `apache-2.0` and `cdla-permissive-2.0` in their
front matter. Read the standard bodies from Apache's official version-2.0 text
and CDLA's official permissive-2.0 page. These are external definitions of the
declared identifiers, not missing repository files or proof of contributor
authority. The two new URLs remain inside the 14-URL cap; retain the scope gap.
