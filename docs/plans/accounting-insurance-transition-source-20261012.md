# Insurance transition: reconstruction method and information limits

12 October 2026. E07/C05 and E01/C03, P17; MC05/08/11/19/22/28/30/32–35,
G7/G8/G13/G16. Protect the new Version 2.47 and all earlier source units.

The existing Ping An example preserves original/restated 2022 figures and
reports that some groups used modified-retrospective or fair-value transition
because full retrospection was impracticable. It does not reconstruct those
groups or explain how the alternative transition methods constrain the
historical information and initial CSM. Investigate that method gap using the
already retained AASB 17 December 2022 compilation, Appendix C. This source is
a scoped comparative design source, not authority for Ping An's ASBE choices.

Question and intent: what distinguishes full retrospective application,
modified retrospective application and the fair-value approach, and which
missing information selects or constrains each route? Read C2–C24 and their
material dependencies; inventory unread transition exceptions explicitly.
Preserve the exact edition/period-start limits. Separate source provisions,
local reconstruction requirements and the issuer's actually disclosed choices.
Do not invent actual group balances, an impracticability finding or a fair
value. Where the source depends on IAS/AASB 8 or 13, inspect retained primary
text if available; otherwise keep that decision/calculation unsupported.

Evidence contract: compare the existing manuscript's disclosed-restatement
example and general transition placeholder with exact source provisions. Pass
requires a condition/dependency map, allowed/prohibited information uses and
clear reconstruction inputs for the three methods. Any finite arithmetic
illustration needs a separate predeclared diagnostic contract first and must
not substitute arbitrary assumptions for historical or fair-value evidence.
Source/edition mismatch, unstated cross-standard transfer, hindsight leakage,
or a fabricated issuer treatment vetoes the claim. Missing source for one
dependency blocks that dependency, not independent source reading.

Default/assumption audit: the retained compilation is a historical baseline,
not automatically the latest applicable standard. Ping An's disclosed method
names motivate the question but do not justify importing AASB rules into ASBE.
The main risk is a reconstruction that appears precise because it fills missing
past assumptions with today's knowledge. The earliest useful check is the
source's exact method-selection and reasonable/supportable-information wording,
before designing examples. No probability weights or numerical defaults are
introduced, no speed/accuracy proxy is a promotion criterion, and no actual
insurer is classified. The skeptical audit passes under these boundaries.

Retain text and selected renders, exact anchors, interpretation/dependencies,
commands, checks, result/decision table and manifest under
data/accounting-master/insurance-transition-source-20261012. Use CPU document
processing only. Integrate only a material supported explanation in a separate

live controls and commit scoped results, then continue ready work. Keep
not_ready, E01/E05/E07/E08/E14, actual facts and independent/human/domain
acceptance open. No engine, installation, GPU/model run, paid review, outreach
