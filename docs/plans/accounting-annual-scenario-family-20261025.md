## Skeptical audit and research intent

The proposed candidate is a finite authored family over a common digest-bound
root and explicit consecutive periods. Each named member retains its assumptions
and operation sequence. The expected failure is dropping failed branches,
reporting unvisited branches as zero, mixing statements between members, or
turning an authored count into probability or exhaustiveness.

Primary pass: full member-result equality to independent annual execution and
joint report equality to each member's actual archived/current book. All named
members must remain represented. Wrong roots/horizons, altered dependencies,
changed source packages, fabricated report availability or accepted tampering
veto the candidate. These trigger repair; only corrupted baselines or an
unresolvable dependency prevent continuation. Check counts and execution time
are explanatory, never financial validity or promotion criteria.

Successful execution establishes only fidelity of this selected reference
interface. Actual histories, exhaustive feasible sets, probability laws, tax-law
admission, annual completeness and production readiness remain unestablished.
