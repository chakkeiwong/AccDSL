## Corrected premise and skeptical audit

The active `data/financial-report-benchmark/coverage.json` selects 24 HTML
reports (Apple 18, Caterpillar 6). Only Apple 2025 Q1 has inline numeric tags;
the other 23 use converted HTML. There are 56 original HTML containers in the
two issuer directories, including retained versions not selected by coverage.
Neither filesystem counts nor empty XML scans define the research denominator.
Use the active selected paths and verify them against their saved SHA-256.

The earlier proposal to scan “24 inline filings” fails the environment/format
audit. The revised plan passes because it separates format, extraction,
comparison nomination and substantive interpretation; it preserves source
versions and never treats absent tags or unequal numbers as semantic verdicts.
The original annual/interim E05 candidates and their repaired anchors remain
historical inputs, not newly discovered conflicts.

## Question and evidence contract

Question: do the selected retained sources supply an incompatible pair of
reported assertions with the same entity/perimeter, date, concept, accounting
basis, units and precision, after revision and extraction explanations?
The comparator is another assertion from the same issuer, not an assumed
economic truth or another issuer. Expected apparent conflicts include changed
dates, reclassifications, differing measurement/precision and conversion errors.

First inspect all 24 selected HTML formats. For those containers, nominate
comparisons for five consolidated balance-sheet captions: total assets, total
current assets, total liabilities, total shareholders'/stockholders' equity,
and the issuer's reported cash caption. Preserve caption wording; Apple's cash
equivalents are not Caterpillar's cash and short-term investments. Use only an
identified statement table and its dated columns, never the first matching
number anywhere in a filing. Where the selected HTML set lacks a matching
annual comparator, inspect the selected annual PDF/text for that date. Keep
the comparison scope explicit; additional subjects need an amended scope.

Separately, inspect duplicate numeric facts within Apple 2025 Q1 using resolved
concept/context/unit identities, dimensions, scale/sign, nil and decimals.
Unsupported transforms or unresolved contexts are excluded with reasons;
they are not agreement. Equal context IDs are not necessary for equal contexts.
Different displayed precision alone is not conflict. Nomination intervals,
where used, are conditional on the declared decimals convention, not exact
economic bounds. Tag anomalies still require visible-source review.

Primary criterion for the bounded unit: exact source-bound observations and
reconstructible nomination/disposition records with no silent failures. E05
promotion additionally requires a genuinely incompatible real pair and its
proposed admission/alternative/invalidation consequences. Zero qualifying pairs
leaves E05 open and does not establish absence of conflicts in the corpus.

| Diagnostic | Role |
| --- | --- |
| Hash, source identity, date/column or extraction mismatch | Continuation veto for that comparison; repair or exclude explicitly |
| Unequal displayed amounts or disjoint nominal decimals intervals | Nomination only; inspect context, source passages and revisions |
| Unresolved basis/perimeter/version/precision | Promotion veto; preserve uncertainty, do not declare a genuine conflict |
| Confirmed normal revision, different context, conversion or tagging error | Reject that E05 candidate; retain the useful failure example |
| Counts, repeated equal facts, parse success | Explanatory only; no semantic accuracy, coverage or readiness promotion |
| No nominated/qualifying pair in the bounded set | Candidate-search outcome, not a continuation veto on other workstreams |

## Assumptions, execution and stop conditions

The active corpus is an inherited development baseline, not a random sample.
Five large balance-sheet captions are a convenience search scope; they are not
a completeness or financial-materiality threshold. HTML table structure and
PDF text extraction are hypotheses checked against dates, headings and originals.
No statement caption supplies a cash restriction or accounting election by itself.
Publication timing and historical byte vintage remain unproved unless separately
supported. Python/BeautifulSoup standard local tools are sufficient; no GPU,
ML framework, package installation, network campaign or stochastic test is needed.

Stop this bounded unit after source-format inventory, selected table comparisons,
inspection of nominations, and a result with exact remaining scope. Repair an
invalid extractor before interpreting its output. Do not enlarge the search
merely to obtain a conflict. Continue another feasible preparation unit when
this one has reached its evidence boundary.

Save scripts, hashes, exclusion records, comparisons, dispositions, actual command,
environment and wall time under `data/accounting-master/e05-comparison-20261007/`;
save the readable result there too. No usable Git commit is available. Preserve
the original corpus, P18/P19 and stopped-controller bytes. The preceding Apple
continuation receives its own completion manifest before this search is treated
as complete.

Pre-mortem: a parser could produce tidy differences from the wrong date column
or parent-only table. Explicit statement headings, dates, source spans and
manual review of every unequal nominated pair distinguish this from a real
conflict. A negative bounded result is evidence about those comparisons only.
