G2/G4/G13; I01/I03/I04. This is the repair for incompatible closed native

## Skeptical audit and evidence contract

Question: can selected return settlement/sale and lease reduction/payment/
depreciation operate on one declared cash balance while preserving each
component's memory, exact journals and refusal behavior? Compare component
effects with original typed return programs and the original corporate lease
kernel. Compare complete original profiles only in their unchanged controls.
No new profile may claim its different context is an admitted original book.

The native return state cannot represent lease accounts and the lease wrapper
fixes its source owner. Projecting either combined opening into those profiles
by deleting accounts or inventing an equity plug would invalidate the test.
Instead create a separately named successor state, reuse the return
prerequisite/monetary programs and the pure lease component kernel, and provide
an explicit shared account registry and module-memory update procedure.
Frozen source-bound wrappers remain unchanged.

Primary pass: exact rational effects equal the corresponding original kernel
for the same component/event inputs; a single journal changes shared balances
once; return and lease allocations reconcile; gross cash flows equal cash
movements; selected module memory changes and other memory is preserved.
Proposals bind the whole before-state and event. Full recomputation rejects
stale, forged or duplicate application. Ordered local pure application is the
only execution claim; no database transaction, source admission or tax/report
completion is inferred. Shared cash shortage must refuse before applying.

## Declared design and assumption audit

Use the 22-account return registry plus ROU asset, lease liability and lease
derecognition gains. Existing names retain their original sign convention:
debit positive, credit negative. The five lease posting names cash, ROU, lease
liability, finance expense and depreciation plus other gains have explicit
successor meanings. Do not alias cogs to cost_of_sales or selling_expense to
cost_expense: those unrelated corporate return methods are not selected.

Store return component/lots/tax memory separately from the named lease rights.
Use one period, date, seen-event set, flow history and balanced account book.
Retain all nonselected return memory and explicit synthetic provenance.
Source observations never become this state automatically. The new owner,
opening amounts, calendar and component-instantiation premises are declared
synthetic assumptions, with numeric lineage to retained test fixtures.
Do not call those assumptions issuer facts or inferred disclosures.

The kernel-reuse choice is an engineering hypothesis. Earliest diagnostic:
the unchanged original fixtures must give the same component effects. The
new shared-state validation then checks conservation and untouched memory.
Amounts, counts and a clean test run are engineering evidence, not research
superiority or accounting compliance. Missing general grammar, arbitrary
histories, group/FX/sector methods and physical durability remain open.
