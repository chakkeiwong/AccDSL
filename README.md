# AccDSL

Read the [latest governing document](docs/AccDSL-latest.pdf) or start with
the [documentation guide](docs/README.md). Project goals and requirements
are maintained in [mission control](MISSION_CONTROL.md).

Build both current PDFs with `python3 scripts/build_pdf.py`. Compiled files and
logs are written to `.build/pdf/`; see the
[build instructions](docs/README.md#building-the-pdfs) for single-volume and editor builds.
