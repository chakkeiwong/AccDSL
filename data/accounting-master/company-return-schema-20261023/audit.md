The repaired classification order is malformed or provably inconsistent,
then known unsupported treatment, then unresolved required inputs, then
static eligibility. Unknowns must never be converted to amounts or Boolean
facts. Arithmetic checks run only when their own dependencies are known.
Text-incompatible scalar strings are invalid in both authoring forms.
Source pointers must be syntactically well-formed; correspondence to the
retained source remains a separate, explicitly checked operation.

The original source packet, P legal-book owner and original dates are the
baseline. Round-trip counts are explanatory; exact identity, dependency
checks, adversarial classification and unchanged legacy behavior are pass
criteria. Any lost source bytes or comparator mismatch vetoes dependent
execution. Static eligibility does not prove source trust, accounting
admission, whole-company execution, current standards compliance or durable
publication. No hardware, stochastic or performance inference is intended.

Defaults remain hypotheses: canonical rational strings are the existing exact
compatibility convention; line syntax is a replaceable engineering choice;
the one-component whole-lot subset is finite scope, not a general inventory
policy. The earliest discriminators are conflicting known/unknown inputs,
false findings with unknown amounts, malformed pointers, zero-unit lots and
typed strings that text cannot preserve. Results belong in checks.json,
manifest.json and result.md, with read-only replay.
