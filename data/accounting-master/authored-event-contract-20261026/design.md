# Selected native event contract

ContractedAuthoredCompanyProgram/1 is an optional, explicitly selected contract
over the retained receivable lifecycle. It retains every full original event
as intent alongside the projected authored event. The selected native module
hash, roles, unit-cost pointer and policy are recorded. There are no callback
names, arbitrary imports or hidden alternative evaluators.

Before each event, the exact native full-input checks and specialization owner
operate on the actual current book. The entire derived request must equal the
authored materialized request after the already declared input projection and,
for scalar collection only, the explicit v2-to-v1 transition choice. Both the
native intended request and projection are retained. Reports/carry keep the
selected native control and preserve-all-memory policy. The existing state
guard remains; no failed state enters the successful prefix.

An alternative half-payment algorithm is valid as an authored algorithm under
its stated assumptions, but it does not satisfy this explicitly selected native
full-payment contract. This profile rejects that mismatch. It does not turn
the native generator into a general portable financial method language. Wider
event-contract authoring remains a separate design obligation.
