**Findings**

1. **06-language.tex, §Scope, para 2 (minor).** "The compiler has six ordered stages … execution-plan construction" is stated in the present tense directly after the sentence introducing the *new* portable authoring boundary. `portable-values.tex` later disambiguates ("The earlier six-stage workflow describes the historical Core 0 frontend"), but a reader of the chapter opening sees two compilers with different stage counts and effects. Repair: prefix with "The historical Core 0 compiler has six ordered stages…" and add one forward reference to the seven-stage portable `CompileRequest`.

2. **06-language.tex, §Types that protect meaning, table (minor).** The table uses Core 0 spellings (`Rate<B>`, bare `YearFraction`, `Instant`/`Period`/`Calendar`, `Measurement<T>`), while L2 of the contract uses `Rate<convention>`, `YearFraction<calendar, convention>`, `InstantValue<T>`, `Flow<T,[start,end)>` and `Approximation{…}`. Repair: label the table "Core 0 type vocabulary" and add a short correspondence line to L2 names, noting the added calendar parameter and that `Measurement<T>` is realised as `Approximation` plus method/environment refs.

3. **06-language.tex, §Types, missingness paragraph (minor).** The five-way enumeration (`notDisclosed`, `notApplicable`, `unreadable`, `withheld`, `unresolvedMeaning`) versus L1's `Unknown{reason, obligation_refs}` + explicit `NotApplicable` variant is a representational split that is only implied. Repair: one sentence stating that the four non-applicability tags map to `Unknown` with that tag as `reason`, and `notApplicable` maps to the `NotApplicable` variant, never to `Unknown` or zero (consistent with L1's LegacyImport rule).

4. **06-language.tex, §A small model, paragraph after second listing (minor).** "Requesting the parent family's exact bounds produces [5,7] for the next year's expense" is only true under `rateShock` (base scenario has both rates at 5%, giving expense 5 for all α). Chapter 11's request makes this explicit via `"scenarios": ["rateShock"]`; the chapter text does not. Repair: "…produces [5,7] under the `rateShock` scenario…".

5. **portable-values.tex, final paragraph vs the Core 0 listing it introduces (minor).** The Core 0 listing's unknown is the *fixed* fraction α (expense 7−2α); LX01's unknown is the *floating* share x (expense 5+2x). Both are arithmetically correct and the endpoints coincide, but the section says the listing "teaches the shared debt family" without stating x = 1−α. Repair: add "LX01 parameterises by floating share x = 1−α; the family and its endpoints are identical."

6. **portable-values.tex, §A portable record, para 1 (minor).** "key is its stable logical name" omits L1's "schema-scoped". Since key uniqueness across different schemas is not required by L1, the manuscript wording could be read as globally unique. Repair: "key is its stable, schema-scoped logical name".
