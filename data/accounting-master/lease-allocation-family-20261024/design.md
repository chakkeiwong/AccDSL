# LeaseAllocationFamily/1

Restricted conditional allocation reference; original source and four-event
lifecycle remain fixed. A request has profile,source_lock_sha256,allocation_domain,
allocation_premise,source_ref,collection_complete,max_cells. Rational endpoints
are canonical strings with explicit inclusion Booleans. The nonempty finite
interval lies within[0,120]. The premise/source reference are explicit supplied
metadata, never evidence admission. Null premise or incomplete membership remain
unresolved. Source-lock bytes and every protected file are checked on each call.

Partition the interval against complete[0,30],rejected_depreciation(30,111],and
unsupported_reduction(111,120]. Empty intersections are absent; nonempty cells
are retained in order. max_cells is an exact integer0..3 and limits original
native witness replays. All cell domains remain visible when budget is exhausted;
unvisited cells have unchecked status and no witness. No global bounds or query
conclusion is available until every retained cell is checked. An analytic
partition is not a claim to have executed every real-valued allocation.

Each checked cell preserves its status,complete-prefix length,failed index/reason,
affine final or last-prefix financial amounts,and one complete native replay.
A representative value is an included lower endpoint or rational midpoint. Its
replay validates the original calculation; the protected affine derivation
establishes the relation across the whole cell within this restricted profile.
Endpoint inclusion is preserved. All amounts depend on the same x.

For complete cells, final ROU30-x,profit-39-x,cash101,liability0. Rejected
last-event cells retain ROU111-x,profit42-x,cash101,liability0. Unsupported
second-event cells retain ROU130-x,profit50-x,cash200,liability-110. Failed
cells are not silently dropped or reinterpreted as impossible actual histories.

Query is explicitly conditional_on=complete_execution and has a list of closed
outcome/domain constraints plus source_ref,premise and max_replays (integer0..1).
This is a separate query-witness budget from the family's max_cells. A nonempty
selection with zero query budget stays partial, with no verified selection or
outcome bounds; its candidate interval remains visible. Targets are final_rou,
profit,cash or lease_liability. Constraints jointly intersect the same x domain.
The returned complete interval,dependent outcome ranges and observed support are
conditional; the full unconditioned partition remains in the response. Empty
selection returns no bounds. No unweighted allocations become probabilities.
A forged result is refused by full recomputation; native inputs are unchanged.

Inherited fixed amounts,findings,annual dates and two-right membership are
conditional baseline hypotheses,not global defaults. Source,accounting,method,
actual-history and production-commit flags remain false. This is not general
lease valuation,actual source reconstruction,annual report/tax close or arbitrary
history composition. Original unknown/refusal categories remain visible.
