# Apple annual filing-event author review

12 October 2026. I checked the retained SEC submissions source against the
corpus source-access record, then read the first-page cover text of each
selected Apple annual report for 2018–2025. Every selected cover identifies
Apple Inc., Form 10-K, and the same fiscal period as one original SEC event.
The event ledger retains the exact accession, primary document, filing date,
acceptance timestamp, SEC metadata row and selected file hash. Forty-three
targeted identity, date and source checks pass. No 10-K/A row for these
target periods appears in the inspected recent arrays; that is bounded to
this retained index snapshot.

The 2018–2024 selected annual PDFs are issuer-hosted/conversion copies whose
dates remain unverified in the frozen selected-report inventory. The SEC
filing events identify the original filing chronology, but cover agreement
does not show that the selected PDF bytes existed unchanged on those days.
The 2025 selected HTML already has issuer-and-regulator filing-date status;
this unit does not reclassify its byte availability. The 56 verified/136
unverified selected-date count remains unchanged. Filing date and acceptance
time are stored as distinct clocks, and the latter is not asserted to be an
exact public-access timestamp.

This is an author source/identity review, not a whole-package historical
forecast test or independent acceptance. No new accounting method or
manuscript paragraph was needed.
