# Direct selected-company source composition

The audited plan and exact result-comparison boundary are in
docs/plans/accounting-selected-company-source-20261026.md. One serialized-order
provenance field may differ; all substantive results and every other field
must match. This distinction is established before running the comparison.
Inspection of composer.input_order confirms its digest covers event-input
names only, so that execution digest must remain exact.

Header: selected_company TEXT_PROFILE BOUND_PROFILE PROGRAM_PROFILE
NATIVE_PROFILE NAME. Four ordered imports name opening, schemas, mapping and
memory_definition by exact canonical hash; all supplied resources must be used.
Imports hold facts/types/mapping, not algorithms. Role, unit_cost_pointer and
policy declarations define the selected contract. Repeated selection_residual
and program_residual declarations preserve their original strings.

Opening and invariant source blocks are mandatory. Each rule names its operation
and contains exactly one eligibility source block and one recipe source block;
the recipe header selects scalar or ordered expansion. Full definitions are
inline. Digest selections are computed from lowered definitions.

Commands use event(id,method,date), typed input(name,type,status,value,provenance),
order(list-or-null), end_event; report(id,cutoff), equity_movements(data),
notes(data), end_report; carry(id,cutoff,retained_account,next_end_exclusive),
equity_movements(data), notes(data), memory_policy(pointer,data), end_carry.
These command data preserve full input order. Reports, carry policies and
mapping retain their original evaluators. There is no native type inference.

The native-shaped opening input is derived from the same facts/selected roles/
policy and projected commands; no second inconsistent fact copy is authored.
The program uses the explicit invariant/rules and original carry policy.
Selection binds context, profiles, roles, cost pointer, policy and derived
template/rule/invariant identities. It does not prove arbitrary accounting-rule
equivalence. Source lowering and opening structural compilation do not execute
commands or pre-judge future contextual checks.

Reuse the strict source reader and bounded UTF-8 span mapping, preserving raw
embedded bytes. Component errors map to parent offsets with their original
granularity. Whole-record contextual errors identify their actual document
scope. The 1 MB source and 4096 declaration bounds are compatibility choices,
not performance evidence. Exact canonical resource hashes and explicit
serialization-order hashes answer different questions and remain separate.
