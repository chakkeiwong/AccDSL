# Closed retained-company composition

RetainedCompanyProgramDraft/1 combines a source-bound P opening, the exact
return authoring reference, a complete 13-event schedule, declared method
capabilities, legal annual reporting and conditional carry. This is a finite
retained-case composition profile, not a general new company-language claim.
Its purpose is to make the Python orchestrator's previously implicit method
choices inspectable and reject a route that has not been selected.

Skeptical audit: inventing whole-company capability from a generic event tag
would reproduce the original gap. Therefore every scheduled event names a
source pointer and content digest, and selects either native return, native
P-tax or retained corporate execution. The registry is provided by local
code; strings cannot import modules, open files or load executable code.
The reference registry is checked against its protected implementation bytes.
The source opening, component and event schedule must correspond exactly to
the retained package. Expected states/journals enter comparison only.

An additional caller admission layer is needed to exercise unknown findings
without rewriting source facts. The source retains its own findings; the
caller supplies explicit per-event review findings. A source true finding
with unknown caller review leaves that step unresolved; false review makes
that selected route unsupported. Caller review cannot turn a false source
finding true. Admission attestations are caller inputs, not facts discovered
in the original packet. The matched demonstration sets them true as explicit
synthetic authoring premises; it establishes no external authenticity.

Typed records and named line text preserve exact source, component, capability,
event and review identities. The finite profile requires all source events in
their original order. A partial execution comes from a missing finding or
capability, not silently omitting inconvenient events. A completed run binds
the program hash, source bytes, method registry and exact native result.
The result contains proposals, annual report and carried opening; a partial
run contains only its valid prefix and explicit unexecuted schedule.

Question/comparator and acceptance follow the active plan. First discriminators:
swapped native/retained routes, unknown caller findings, malformed records,
changed source owner/bytes and unknown capabilities. Primary evidence is exact
whole-result equality with the protected 253-check reference, not more schema
fields or a balanced final cash total. Defaults are the finite retained case,
exact arithmetic and replaceable line syntax. No new tax/accounting facts,
general capability claim, durable publication or forecast inference.
