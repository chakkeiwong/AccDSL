3.14
Persistent parameters and particle approximation
A particle approximation can reduce computation after a probability model is chosen. It
does not create that model. A type with probability 0.01 has probability 0.99100 > 1/3 of
disappearing from 100 independent multinomial resampling draws. No new evidence is involved
in this loss. Rare but material types therefore need explicit support checks, stratification or
separate conditional computations, with the resulting approximation stated.
For state-space models with persistent unknown parameters, SMC2 combines parameter particles
and state filters, with particle-MCMC rejuvenation (Chopin et al., 2013, Section 3.2, equation (7),
Proposition 1, Appendix A). Its extended target has the desired parameter posterior as a marginal
under the source assumptions. Finite particles still approximate that posterior; exactness of a
target marginal does not mean that one finite run represents every possible type. The unbiased
full particle likelihood estimate used in this construction must be distinguished from an arbitrary
estimated likelihood ratio.
The inspected author-linked modern implementation creates a state filter for each parameter
particle, runs that filter through the current observation date when evaluating a proposed
parameter, and incorporates a likelihood correction when increasing the state-particle count.
These operations have real time and memory costs. Retaining only filtering arrays differs from
retaining complete genealogies. This is a candidate for explicitly probabilistic filtering, not a
replacement for symbolic unweighted historical ambiguity.
3.15
Changing particles without changing the target
Increasing the number of particles can change an inference result even before new evidence
arrives. The reason is that a likelihood estimate and its random construction belong to the
state used by particle MCMC. Replacing the estimate with another unbiased estimate does not
automatically preserve their joint distribution. A test that examines only current company-type
probabilities can miss the error.

produces a nonnegative unbiased estimate ZN,v(θ, u) of that likelihood. Assume the normalizing
constant Cv is finite and positive. The joint target weights the random construction by the
