# AccDSL design documents

Read the [canonical governing PDF](../AccDSL-latest.pdf), Version 5.10, or its
[LaTeX root](../AccDSL-latest.tex). The [documentation guide](../README.md)
explains the stable links and current review status. Resolve a source link and
build in its target directory so relative dependencies remain valid.

The [standalone simulation volume](../AccDSL-simulation-foundations.pdf) contains
the same 26 chapters as Part I of the governing document: 155 body pages on
compatible histories, persistent uncertainty, learning, debt and equity,
scenario computation, failure cases and proposed methods.

The obsolete Version 1.2 root, PDF and build products are
[archived](../archive/accounting-product-design-v1.2-20261026/ARCHIVE.md), together
with a source dependency copy and content hashes. Shared historical chapters,
spec, fixtures and research files remain here because existing generators
and historical evidence use them. They are not the current manuscript.

The [mission](../../MISSION_CONTROL.md),
[requirements](../plans/accounting-mission-requirements.md),
[product checkpoint](../plans/accounting-product-design-checkpoint.md) and
[master checkpoint](../plans/accounting-master-checkpoint.md) record scope and
acceptance. Versioned manuscript candidates live under [proposal](proposal/).

The [simulation result](../../data/accounting-master/simulation-monograph-20261026/result.md)
records source preservation, citations, exact examples, build checks and rendered
review. Supporting [research](research/) and [review](review/) records retain
source qualifications. Independent human acceptance and full product readiness
remain pending.
