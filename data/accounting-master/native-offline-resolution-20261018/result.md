## Source consequence

alternate cache files, and parser-stream transformations. Offline lookup can
return a path whose bytes are absent. A future adapter must therefore check
the actual bytes opened and preserve the transformation and effective
configuration, not merely set an offline option. This is a source-based
requirement; the current work establishes no runtime network or parser result.
