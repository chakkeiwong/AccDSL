# Exact range evidence conditions

Question and comparator: whole-family finite account-sum envelope versus
the complete original native transitions and exact parent constraints.
All type/date/identity and strict input boundaries reuse the checked query
validator. No source observation or accounting prerequisite is added by a query.

Completeness: every original branch must be infeasible or have both endpoints
certified before a global range is published. The shared cell budget counts
each branch once, with optimizer/proof calls inside its elapsed/resource limits.
Unknown branch or endpoint and unvisited branch each veto global certification.
Proof statistics, passing test count and selected witness extrema are not criteria.

Endpoint validity: original feasible branch; finite closure endpoint; no better
original value; original endpoint existence/nonexistence; full native replay
when attained. Given a nonempty convex rational-linear branch, every closure
point is approached from a feasible point by convex interpolation. Therefore
a feasible closure endpoint and no better original value identify the tight
infimum/supremum. This local argument applies only to the inspected affine
conjunction, not arbitrary nonlinear or disjunctive regions. General infinity
certificates are outside the supported range profile.

Global aggregation: lower=min branch infima; upper=max branch suprema. A finite
number of complete branches preserves tightness. Endpoint attainment is the
existence of an attaining extremizing branch. Empty family is separate from
unknown and never supplies numeric endpoints. An envelope may contain holes.

Verification: full saved request/result round trips; independent Fraction value
checks; recomputed bound/status/proof metadata; alternative valid witnesses
and conflict cores accepted after checking. Existing138 relevant regression
methods cover range,query,native transitions,method prerequisites and solver
resource/strict-bound behavior. No new default, actual-source interpretation,
stochastic ranking or whole-language conclusion follows.
