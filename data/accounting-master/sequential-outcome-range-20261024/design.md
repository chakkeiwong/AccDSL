The closed query contains profile,family,prefix,type,terms. It uses the preceding
predicate-query validation for distinct accounts, canonical rational coefficients
and exact original event-dated types. An internal equality-to-zero record is
used only to share validation and expression construction; no equality is added
to the parent's problem. The full family and every constraint remain unchanged.

Each original branch is solved with the requested affine expression as objective.
All numeric inputs have finite exact intervals in this fragment; an unbounded
endpoint therefore vetoes the result. A shared branch-cell count and remaining
elapsed budget cover the complete family. The solver's endpoint checks are
supplemented with exact closure-endpoint feasibility, absence of a better
original value and original endpoint attainment. A resource-unknown proof
prevents certification. Every attained endpoint includes a complete witness and
original native two-event replay; Fraction arithmetic checks the query value.

If every branch is infeasible, return empty_family and no bounds. If every
branch is either checked infeasible or has both finite certified endpoints,
the global lower/upper endpoints are the minimum/maximum of the branch
endpoints. supporting_branches names branches with the extremal bound;
attaining_branches names those that actually reach it. Both can differ: the
high-carrying branch reaches inventory80, while the low branch has supremum80
but does not attain it. Global attainment is true when any extremizing branch
attains the endpoint. This distinction repaired a pre-recording test expectation;
the original numeric bounds and attainment calculation were correct.

Incomplete coverage exposes visited branch evidence with globally_certified
false and no global bounds. A feasible witness still establishes nonempty.
An exact envelope does not prove every interior point attainable. Domain,
continuity and observation premises and target obligations are retained;
missing premises halt, while unresolved target obligations keep the answer
candidate-only. Actual outcomes and source/accounting admission remain unknown
or false. No invented probabilities or simulated prediction is introduced.

Verification recomputes endpoints and coverage, checks alternative endpoint
witnesses with original replay, and rechecks supplied infeasible conflict cores.
Forged values, attainment, state, coverage or proof reject. Unattained endpoints
cannot carry a witness. Serialization is tested before recording and saved
replay before active controls advance. Original parents stay hash-protected.

Elapsed limits govern scheduling and solver calls, not hard interruption of
bounded Python preparation/replay. Near-deadline coverage can vary. General
unbounded/nonlinear ranges, arbitrary sequences, interior-feasible-set queries,
actual company state and independent validation remain separate work.
