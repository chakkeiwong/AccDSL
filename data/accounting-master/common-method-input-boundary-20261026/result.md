# Selected requirements do not establish native invocation eligibility

26 October 2026. The bounded NativeRequirementLink/1 binds retained regulatory
requests and their submitted bytes to exact requirement manifests, schemas,
input pointers, roles and complete native contexts. It reuses the original
MethodInputBinding/2 and version-selected evaluator; no new predicate engine.

All 271 retained regulatory exchanges pass the original native response audit.
All 813 versioned text/typed pairs agree with the existing evaluators and an
independent date comparison. Nineteen malformed-link/binding cases and nine
unknown/capability cases pass. All 191 pinned source files remain unchanged.

The native dispositions are 10 completed, 75 replayed, 50 unknown acknowledgements,
96 rejected and 40 partial. Selected date requirements pass for 95 of the 96
rejected exchanges, all partial exchanges and all unknown acknowledgements.
They therefore cannot establish native eligibility, completion or a known
publication outcome. A wrong native signature is separately refused by the link
in each requirement version. The native records and worlds are never mutated.

## Review and environment correction

The strongest alternative explanation is that this only tests a narrow date
subset. That is the stated scope: the rejected/partial native comparisons expose
the insufficiency of that subset rather than claiming universal coverage. An
independent implementation remains untested. Native expectations come from the
protected auditor, whose own accounting/source scope is not promoted.

The active plan proposed standard-library-only checks. Inspection showed that
the retained native auditor imports the already-installed jsonschema package.
Reusing it preserves the actual native comparator; no installation occurred.
Its archived ROOT is explicitly rebound to the repository root because the
snapshot lives under inputs/. Neither its file nor any archived writer is run
or changed. The exact command, environment and hashes are in run-manifest.json.

No continuation veto fired. Native refusals reject individual requests; they
do not reject the simulator design. The next internal work is manuscript
integration and a refreshed common-language dependency audit.
