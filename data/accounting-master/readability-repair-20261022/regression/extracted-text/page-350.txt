Take three constructed
observations of the same quantity: 100 at zero decimals, and 99.6 and 100.4 at one decimal.
The first has bounds [99.5, 100.5]; the other two have bounds [99.55, 99.65] and [100.35, 100.45].
Each precise observation overlaps the coarse one, but the precise observations disagree and the
three intervals have no common point. The inspected consistent-pairs reduction can remove
the coarse occurrence while leaving both precise occurrences. The consistent-set path instead
reports the inconsistent set and falls back to complete-subset reduction. Neither operation
establishes which precise observation the accounting analysis should accept (Arelle contributors,

These paths require their own admission checks. The initial grouping considers validation state
and the availability of a concept, type and context; a singleton bucket is not itself a validity
verdict. The numeric consistency path also expects an inferred decimal accuracy from its helper,
which returns no value when the fact’s decimals attribute is absent. An adapter must not
silently reinterpret an unsupported or unvalidated case as an ordinary consistent numeric fact.
It retains the declared decimals and precision, validation state, nil state, concept, full context
and unit, together with the particular comparison operation and its options (Arelle contributors,
2026a).
Finally, the inspected deduplicated-instance export removes fact nodes from the model’s
underlying tree before saving. The controller performs it at the end and warns that subsequent
use of the modified model can be unreliable. The proposed exchange therefore copies every
original occurrence and its diagnostics before constructing any optional reduced view. A view
records its input members and selection rule; it does not replace the source record. This
preserves disagreement for review while allowing a query to avoid counting an accepted repeated
amount twice. These are requirements derived from pinned source inspection and independently
checked constructed arithmetic; an executed adapter and actual-filing validation remain to be
established (Arelle contributors, 2026a).

The same balance can survive different source identities
Apple’s following-quarter filing provides an actual counterpart to the constructed examples.
Its balance sheet repeats the 28 September 2024 comparative balances already examined in
the company case. The retained annual HTML is a converted presentation without inline tags,
so it cannot supply the proposed inline trace. Instead, the selected comparison follows the
next-quarter inline comparative amounts to the retained annual XBRL instance. This compares
reports of the same endpoint across two filings; it does not show that one file was extracted
from the other (Apple Inc., 2025c, 2024c,b).
