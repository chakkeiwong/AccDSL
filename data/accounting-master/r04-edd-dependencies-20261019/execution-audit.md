# Source correspondence audit

19 October 2026. P15/P17/P19; MC01–05/23/26/28–35.

The retained plan survives the skeptical audit with a narrower conclusion:
file/AST correspondence and explicit index arithmetic can establish source
observations, but cannot reproduce an installed model or published experiment.
The comparator is the exact pinned EDD source, the earlier pinned PubTabNet
metric, and the published supplement linked by the acquired ECVA index.
No replacement baseline or financial task is introduced.

Research intent: determine whether preparation, loading and metric definitions
agree, and identify remaining reproduction assumptions. Expected failures are
documentation drift, version ambiguity and differences between metric wrappers.
The primary pass criterion is an accurately bound, scoped account of those
agreements and differences. Wrong identity, an uninspected dependency presented
as checked, or source scores presented as a supported ranking veto that claim.
Protection failure or held execution vetoes continuation. Source discrepancies
trigger a protocol repair; they do not veto the research direction.

Defaults and assumptions: the current source commit is a source comparator,
not a verified experiment-era revision. Dependency lower bounds are unreviewed
environment hypotheses. The supplement's scores describe its reported sample;
there is no local replication or uncertainty-based ranking. Text extraction is
a reading aid: physical pages 3 and 4 were rendered and inspected to verify
the thresholds, runtime conditions and encoder table. All six supplement pages
have now been read in extracted form, including the reference tail. References
are bibliographic leads, not inspected technical sources. The large ECVA index
was searched only for the matching paper entry; it was not read in full.

Six URL acquisitions are complete. No further acquisition belongs to this
unit. The prior session's recorded curl fields will be transcribed explicitly
as such and checked against retained bytes/headers; no independent packet log
is invented. Supplement provenance is the actual index link, not model recall.

The finite loader diagnostic will implement only the index concatenation in
the inspected source, using standard-library integer lists. For a five-item
illustration it distinguishes raw-index padding from shuffled-prefix padding;
a one-item illustration exposes out-of-range indices. These are local static
deductions, not observations of the real dataset or a training failure.
Metric comparison parses Python AST only. It never imports acquired code,
APTED, lxml, NumPy, PyTorch, the Java evaluator or the SSH example.

library or threading behavior. Check the wrapper differences explicitly and
retain dependency/runtime uncertainty. The adjacency-threshold discrepancy
does not identify the settings actually used for published Table S1. The
reported 13.7 minutes measures metric evaluation, not model inference. No
finding here requires a manuscript change: chapter 3 already distinguishes
cropped-table recognition from financial-report and accounting correctness.
