# Attach formulas and explicit mappings, not selected witnesses

24 October 2026. The inspected temporal contract exposes a complete scalar
measurement conjunction after validating time/quantity roles. The conditional
history contract exposes exact symbolic openings, event amounts, dated linear
snapshot constraints and unresolved target obligations. Both use the same exact
solver primitives. Their variable namespaces must remain disjoint until an
explicit mapping equation connects them.

The attachment definition contains both complete parent definitions, snapshot or
period-movement mappings, explicit proposed mapping premises and additional
unresolved obligations. It never accepts parent result/witness objects. Rebuild
both parent formulas, rename all symbolic variables into disjoint namespaces,
and conjoin every original bound/equation with each mapping equation. Preserve
original parent hashes and full definitions. No solver-selected assignment is
substituted into the other parent.

A snapshot maps an instant observation to an account/monetary-memory linear form
at the identical declared history snapshot date. A flow maps a period observation
to the signed net contribution of supplied event incidence during its exact
half-open period. It excludes opening balances. Mapping value types must equal
the history's monetary context/dimension/scale, and quantities are named explicitly
with proposed interpretation premises. A correct sum or matching date alone is
not population admission. This first layer supports only the authored monetary
history fragment; it does not map consolidated real-source captions to legal books.

Each measurement observation may have at most one mapping. Unmapped observations
remain variables of the original measurement family and produce unresolved target
obligations; a relaxed candidate can still be checked, but target existence remains
unknown. Missing explicit mapping or parent premises prevents solving. Parent
history obligations remain in the result. Attachment-level completeness means
all declared inputs/mappings are accounted for, not complete real-company scope.
All admission and execution flags remain false.

The combined solver budget is caller supplied. Parent validation uses the same
limits, except max_slots=0 when validating the event-free measurement conjunction;
the combined problem retains the actual history slot count. Maximum combined
variables is 256, with 4096 mapping terms and the existing size/rational limits.
This is an explicit bounded reference scope, not a production default.

Evidence contract: separately feasible parent systems whose mapping is infeasible;
multiple compatible parent assignments where choosing an arbitrary measurement
witness would discard a valid history; independent original-parent Fraction
checks and snapshot/flow replay; wrong dates/types/populations, modified formulas,
partial mappings, strict bounds and zero budgets. Unknown/infeasible remain
distinct. No actual retained issuer opening is created. The existing retained
network is used only to demonstrate that its real contexts cannot silently attach
to the synthetic book. CPU-only tests, no forecast or statistical ranking.
