# Inline value construction: evidence and reader contract

13 October2026; baseline2.68/2d901f0. E14/E01 and MC/G mapping as in plan.
Question: what has already happened when the adapter reads an inline value?
Comparator: proposal scale-once and source-occurrence requirements. Pass requires
exact pinned call paths plus independently checked constructed consequences.
Unknown transforms/validation, unresolved continuations and unknown source
identity veto stronger claims. Source corruption vetoes continuation; field
loss or double transformation triggers design repair. No runtime or standard
conformance claim is authorized. Source code alone does not prove validity.

Skeptical audit passes: ModelInlineValueObject.value visibly consumes rawValue,
dispatches a transform, then applies numeric scale/sign. Both textValue and
stringValue delegate to value. rawValue delegates to innerText and can collapse
whitespace. Read those immediate helper bodies before claiming raw preservation.
Prior same-host sandbox DNS failure and successful trusted fetch justify the
same bounded trusted official-source route. Preserve exact requests/hashes.

Defaults: selected commit comes from existing dossier (baseline); constructed
literal/sign/scale inputs isolate source mechanics (hypotheses); Decimal is an
exact arithmetic diagnostic, not library execution; continuation behavior must
follow the source and loading prerequisites, not an invented generic parser.
Failure checks: source hashes, call order, explicit nil/invalid branches and
comparison with preserved earlier prose. No benchmark or stochastic ranking.

Reader: accounting product reviewer needing to understand why a tagged value
can differ from its source spelling. Reactivate the existing1,234 example;
locate transform/sign/scale in the source; show double application and explain
why rawValue is still an assembled reading. A compact additive passage should
connect original bytes and node locations to the normalized amount. Earlier
text/math/citations remain protected. Voice and acceptance remain provisional.
Artifacts: source receipts/findings, constructed checks, result, candidate if
material, build/render checks, master refresh and explicit-path commit.
