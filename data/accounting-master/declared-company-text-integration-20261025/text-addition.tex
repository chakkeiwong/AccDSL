\paragraph{Author the sequence while retaining its declared definitions.}
The matched \texttt{DeclaredCompanyText/1} frontend expresses those same commands
as text. Four separately checked content hashes identify the opening book,
schemas, method registry and statement map. These definitions remain imported
data; the following language authors their operation sequence. For example,
after its program header and four import declarations, a sale can be written as:
\begin{lstlisting}
event "sale.2027" method "sell" on "2027-02-01";
  input "proceeds" known "40/1" because "Synthetic assumption";
  input "cost" known "15/1" because "Synthetic assumption";
  input "approved" known true because "Synthetic assumption";
end_event;
\end{lstlisting}
Each declaration occupies one physical line. Each amount's type comes from
the selected registry entry, including its company context, currency and units.
A finding can instead be explicitly unknown, with its reason and provenance;
compilation preserves it for the method to evaluate at the actual command.

A report command supplies its cutoff, direct-equity explanations and note
requirements. A carry adds its retained-equity account, next period endpoint and
one policy for each memory leaf. Preserve, typed reset and next-period-start
policies retain the same meanings as their data-record counterparts. The compiler
resolves reset types from the declared memory schema rather than guessing units.
Missing policy coverage remains a carry refusal, so earlier successful commands
remain visible. Repeated event identities and invalid chronology likewise retain
the checked engine's exact refusal and preceding book.

Compilation verifies every imported hash and returns the resolved program,
dependency identities, source hash and physical declaration locations. Unknown
fields, repeated declarations, malformed scalar values and unchecked imports are
rejected. It neither evaluates Python nor treats a serialized object as a command.
The two company charts reproduce their full data programs and execution results;
an independently authored sale and interim report also recover cash USD~140,
profit USD~25 and equity USD~125. Complete and stopped programs are compared,
including unknown findings, missing carry policies and changed ordering. These
checks establish the finite frontend's correspondence; authoring complete method
algorithms, broader accounting policies and all company disclosures remains work
for the wider language design.
