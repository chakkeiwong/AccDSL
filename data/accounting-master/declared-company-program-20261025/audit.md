# Pre-execution skeptical and default audit

Question: can supplied company events, statements and carry compose over periods
without precomputed future state or lost refusal evidence? Comparator: separately
written manual calls to the three pinned engines plus independent rational
cash/profit/equity/loan arithmetic under distinct charts. Existing native annual
programs remain separate; this adds a declared-book composition boundary, not a
replacement accounting engine or another claim of full-company completion.

Primary pass: all requests/results and final books match manual composition;
independent financial quantities and two-period opening lineage agree. Hard veto:
changed engine pins, hidden date/memory changes, lost prefix, false completeness,
stale replay or wrong balances. Structural/semantic failures trigger repair;
invalid indispensable comparator is a continuation veto. Counts/time explain only.

| Choice | Provenance/status | Justification | Failure mode | Early check |
|---|---|---|---|---|
| Explicit sequential commands | Existing plan; reviewed bounded default | Unambiguous same-day order | Accidental sorting | Reverse-order test |
| 64 commands, 8 MiB trace | Convenience safety hypotheses | Bound work and output | Rejects larger valid cases | Boundary/refusal test; no scalability inference |
| Synthetic opening and events | Existing reference book | Reproducible arithmetic | Mistaken real-company admission | All admission flags false |
| Observation cutoff | Plan hypothesis | Allows interim/year-end reports | Infers absent events | Date-only trace and incomplete status |
| Fixed chart/memory schemas | Checked engine limitation | Exact reuse | Misses dynamic collections | Reject mismatch and state scope |
| Preserve memory across carry | Authored example policy | Retain loan history | Wrong real fiscal policy | Verify every leaf; no policy inference |

Premortem: the wrapper and comparator could share an engine bug, so independently
check cash, inventory, debt, profit and equity. A passing fixture cannot establish
source admission, financial reporting compliance, notes completeness, production
readiness or predictive accuracy. Static checks must not run economic prerequisites
against the wrong opening state. Audit passes for the exact design.md contract;
inspect adverse tests before recording. Result/manifest and preserved attempts
will record commands, environment, hashes and interpretation.
