# Source and terms review

I read both crates' source package manifests, MIT texts and Apache grant,
redistribution, patent, notice and disclaimer provisions. I checked the PyO3
README grant, both bundled runtime licence copies, and `unicode-bidi`'s
COPYRIGHT and source-header qualifications. Retained witness files are exact
archive members, not newly drafted licence text.

Registry metadata, the parent lockfile checksum and local archive digest
agree. Source-grant evidence is therefore stronger than an issue allegation
or the parent's stale third-party version list. It remains narrower than
proof about installed compatibility, a chosen distribution or legal
acceptance. No claim about runtime speed, Unicode correctness or OCR
accuracy was tested or admitted.

The source ledger separates versions, licence alternatives and minimum
Rust declarations. The latter are source metadata only: no available
compiler or actual wheel build has been checked.
