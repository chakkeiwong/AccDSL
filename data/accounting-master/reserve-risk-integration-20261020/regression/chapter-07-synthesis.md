# Chapter 7 — authoring the same financial meaning

Version 3.45, physical pages 97–104, inspected in order. Author evidence only;
independent, domain and human acceptance remain pending.

The language chapter converts the previous mathematical distinctions into
authoring and interchange obligations. It distinguishes historical Core 0
examples from the new portable format and separates whole-company typed
construction from the first bounded textual frontend. Neither distinction
reduces the required company scope or claims an implemented compiler.

Types preserve units, dates, shared unknowns and explicit laws. Portable
records add exact rational representation, schema-controlled missingness,
reference closure and reproducible bytes. Their digest identifies a record,
not economic equivalence or source truth. The debt listing then demonstrates
one shared unknown, whose named endpoints neither exhaust the continuous
family nor create probabilities.

Posting rules propose batches under explicit effects and applicability.
Alternatives retain parent constraints, while corrections create revised
evidence views. Package order cannot override a mandatory rule, and a syntax
migration cannot disguise changed accounting meaning. Typed failures give
these distinctions practical recovery paths.
