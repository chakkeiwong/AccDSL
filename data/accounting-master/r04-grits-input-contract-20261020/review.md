# Source and proposal review

The source findings distinguish present checks from missing ones: _get_n_cols
does reject ragged rows; HTML conversion rejects failed parses and location
requests; the cell-list entry rejects a flat list. A blanket statement that
the library validates nothing would be wrong. The missing checks concern the
specific text/span/geometry domains, not all input handling.

The claimed mathematical target is finite set-union IoU. The local computed
quantity follows the inspected elementary floating expression. For identical
finite positive-area boxes the exact target is one, whereas four extreme
finite examples produce NaN or zero. Fraction arithmetic is exact for the
stored binary float values; it makes no claim about unseen decimal originals.
NaN/infinite/degenerate inputs have distinct validity or convention states.

The strongest alternative explanation is that an upstream validator and normal
document coordinate range exclude all problematic cases. That would limit
practical impact without creating checks in the inspected functions. The
small local examples establish neither installed output nor historical metric
changes. Positive finite input checks cannot catch all derived overflow or
underflow, which is why the proposed contract checks intermediate quantities.

The proposed profile intentionally adds conditions to the library interface.
These are replaceable engineering choices, not new user requirements or a
default. Required budgets and normalization remain unselected. The fixtures
check a narrow validator model; they neither implement the full contract nor
validate accounting content. Partial multi-metric accumulation is a
conditional code-path observation; no external runtime was invoked.

Ten corrupted summaries were rejected, but integrity/claim checks are not
native conformance. Six ledgers do not finish the literature mission. The new
assignment-upper-bound question has a separate audited plan next. No protected
bytes changed and no continuation veto fired; continue that ready inquiry.
