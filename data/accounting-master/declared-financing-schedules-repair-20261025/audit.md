# Skeptical schedule audit and evidence contract

Main question:can verified common-book events explain debt,interest and equity
movements and separately identify missing accrual days? Baselines:independent
amounts and interval unions,raw verified transition postings and existing financial
reports. Exact method identity defines classification;registry keys are labels.
The old working-capital netting bug requires gross-posting checks from the outset.

Primary pass:two-chart and selected-report/carry/stopped cases reconcile every
scoped account;coverage flags follow actual intervals,not profits or balances;
v1/v2 working-capital amounts match on compatible inputs. Veto:tampered result,
unknown scoped gross movement,hidden memory change,false completeness or lost source
lineage. Candidate rejection triggers repair;invalid indispensable trace blocks
that request only. Counts/runtime are explanatory. No stochastic ranking.

Defaults:positive credit presentation follows existing reports;the exact policy
and interval set comes from the checked financing builder;the full program is
recomputed instead of trusted;current-period opening follows actual carry lineage.
Failure modes:netting hides gross movement;carry hides omitted interest;wrong
policy gives same totals;post-cutoff events contaminate selected earlier report.
Early checks:offsetting gross movement,changed policy,rehashed tamper,missing final
interval,foreign cursor edit and earlier successful report from a stopped program.
These tests do not prove real instrument/accounting admission or complete disclosures.
Audit passes for the defined scope. Record plan,commands,environment,hashes,tests,
independent comparisons and a decision table before integration.
