17.24.2
Check the reason for each rejected rule
A saved list of surviving rules is insufficient evidence by itself.
For every excluded total
assignment, the result names a known financial row that refuses it. A first-stage refusal must
match the rule’s first action at that row’s message. A second-stage refusal must also match
the second action, using the second key that retains the actual first message and action. The
checker validates these witnesses and requires the surviving and rejected assignments together
to cover the entire fixed rule universe. It also reconstructs the conclusion, unknown source pairs,
pending domains and support paths from the checked source search.
The finite comparison checks every saved endpoint and selected partial results against an
independently evaluated policy population.
Altered refusal witnesses, premature feasible
conclusions, missing pending evidence and changed identities are rejected. The result checker
still uses the established source-to-row mapping and policy oracle; it is not an independent
redevelopment of all accounting and observation semantics.15
This establishes logical continuation for the supplied two-date question. It does not test crash-
safe file storage or establish actual information delivery. Transporting a result to changed
observation declarations, extending the horizon and admitting company evidence require further
work.
17.25
Changing the observation declaration
The fixed-domain result raises a practical question when a modeller revises the observation
declaration. A message may acquire a new label, or a formerly pooled observation may be
separated into more informative messages. Both changes alter the encoded decision keys, but
they have different consequences. A new spelling can preserve the same choices exactly. A new
distinction can let a manager choose different actions where the old declaration required the
same action. The comparison must say which change has occurred before reusing a computed
policy set.
17.25.1
A different label must preserve the entire decision key
Consider replacing every first-message label with a distinct new label and doing the same for
the second messages. The substitution must be global across source heads: two equal old
messages must remain equal, and distinct old messages must remain distinct. A substitution
chosen separately for each source could reveal the source’s identity and therefore change the
information available to the manager.
The second-stage key contains the first message and the manager’s first action as well as the
current message. Consequently, renaming the first message also changes its occurrence inside
second-stage memory. The joint comparison generates this full key correspondence from all
original financial and observation-head triples, before inspecting completed source outcomes. If
the correspondence is a bijection, the old total action assignment can be permuted to the new
key order. Inverting the permutation recovers every assignment.
The refusal evidence travels with the assignment. A rejected rule keeps the same financial-row
identity, but the checker must confirm that the renamed rule still takes the actions that row

17.25.2
A new distinction permits an old rule to ignore it
Now suppose a refined declaration distinguishes messages that a coarse declaration pools. The
financial rows, action meanings, source chronology and decision dates are unchanged. Let Dc
and Df be the coarse and refined sets of full decision keys. A surjective map e : Df →Dc erases
the new distinctions. It must also erase the first-message distinction wherever that message
occurs in second-stage memory. Surjectivity ensures that every coarse decision key still has a
refined counterpart.
A coarse rule π assigns an action to each key in Dc. Its lift π↑on Df ignores the added
distinction: at a refined key z, it takes the coarse action at e(z). Let Cc and Cf be the candidate
populations for the same selected source pairs under the two declarations. With unchanged
financial refusal conditions, the checked relation is
π↑(z) = π(e(z)),
{π↑: π ∈Cc} = {ρ ∈Cf : e(z) = e(z′) ⇒ρ(z) = ρ(z′)}.
(17.38)
The right-hand side selects refined rules that take the same action whenever the new messages
collapse to the same coarse key. To see why the equality holds, substitute the coarse action at
e(z) for each refined action in a refused financial row. Erasing that row’s decision keys produces
exactly the coarse refusal condition. A lifted coarse candidate therefore passes every refined
row. Conversely, a refined candidate constant on each erasure class defines a unique coarse rule,
and the same substitution shows that it passes the coarse rows. The equality concerns the same
finite decision problem under two declared information restrictions.
In the between-date correction case, restoring the original first-message distinctions from an
artificially collapsed first message changes the candidate population from zero to 16 total rules,
with four additional reached-row signatures. Restoring the second-message distinctions changes
two total candidates to 16, with three additional signatures. A signature records the financial
rows reached by a rule’s actions; it is not a probability distribution or an observed company
path. The comparison verifies the reached rows of each individual lifted rule, so equality of
aggregate signature sets cannot conceal a wrong pairing.
The distinction matters particularly when required sources are unresolved. In the late-conflict
example, refinement expands eight total assignments to 2,048, yet no financial row is selected
and no additional reached-row signature appears. Those assignments do not establish feasible
company behavior. Inconsistent clocks produce no assessed policy population at all. If a refined
domain exceeds the key allowance, its policy comparison remains unassessed even when the
coarse domain has been evaluated.17
These are conditional comparisons of supplied observation declarations. The extra distinctions
must still be justified as information available to the actor. Their finite effects on permitted
actions do not measure utility or predictive accuracy. Both relations also retain one financial
source view across the two decisions; allowing a financial correction to change that view requires
an account of what was believed earlier and which economic history continues afterward.
