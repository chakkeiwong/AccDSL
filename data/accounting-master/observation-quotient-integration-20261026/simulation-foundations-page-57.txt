8.13
Counterexample-guided refinement
Begin with a coarse outer model. If it proves the desired bound, the query may finish. If
it returns a harmful candidate, validate that candidate against full constraints. A feasible
candidate is a genuine witness; an infeasible one identifies a lost dependence and motivates
refinement.
The marginal interest-cash rectangle admits (7, 90), but C + I = 95 rejects it. Adding that
relation removes the spurious combination without enumeration. Other refinements can restore
currency-maturity dependence, collateral ownership or persistent contract identity.
This is a proposed reasoning method, not a universal termination result. Refinement may
exhaust resources. The returned bounds and unresolved region should remain available, together
with the dependencies still preventing a definitive answer. A resource limit is not an economic
default or a proof that the region is empty.
8.14
Caching has an economic scope
A cached answer depends on evidence, assumptions, contracts, policy, observation model, horizon,
requested outputs and numerical method. A change in any relevant component invalidates it.
Company name and scenario label are insufficient cache keys.
An aggregation checked for one-year interest may fail for three-year refinancing. Adding a new
observed covenant can invalidate an information summary. The system should record the query
class covered by an abstraction and require revalidation before broader reuse.
Provenance remains separate even when computations are shared. Two sources supporting one
fact need not duplicate arithmetic, but their independent support matters if one is withdrawn.
Execution identity must not replace source identity.
8.15
Trees as selected explanations
A small tree is useful for showing information arrival, choices and counterexamples. It can be
generated from the symbolic family for a question. Nodes should identify whether they are
exact worlds, samples, regions or hypothetical observations.
A representative tree is not exhaustive unless the finite model and coverage establish that claim.
Branch probabilities require a measure. Pruning a display branch must not silently delete it
from the calculation or renormalize remaining probabilities. A region can instead remain visible
as an unresolved aggregate.
A hybrid interface can show important branches, formulas and bounds together. Users expand
regions affecting their decisions. This preserves explanation while avoiding compulsory exhaustive
materialization. The underlying family remains authoritative when a new question requires a
different partition.
8.16
Budgeted computation
A query should state resources and acceptable result types. Exact values, certified bounds,
feasible witnesses and statistical estimates are distinct deliverables. If exact work exceeds
budget, return partial bounds and unresolved regions. Do not substitute an unsupported point
merely because the interface expects a number.
