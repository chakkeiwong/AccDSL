Cross-contract finding: the retained native acquisition `journal` schema uses
nonempty lines. A fully prepaid bill needs no monetary entry but does consume
an advance allocation. The new authored method must declare its own explicit
state-only case in its profile schema, under the existing atomic authorization
and commit procedure; it cannot fabricate debit/credit lines or claim native
acquisition compatibility. P17-10 now supplies that exchange in Version 2.77 (899 documentary checks);
wider interface acceptance remains open. This is a design repair, not permission
to run a new profile.
