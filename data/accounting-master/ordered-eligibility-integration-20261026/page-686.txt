Calendar adjacency is a narrow additional binding. After strict date validation, it compares the
two date ordinals and returns true when the right date is one calendar day after the left. An

follow the same relation. This is a civil-calendar condition, not a business-day adjustment
or a fiscal-calendar policy. The unchanged chronology and interval checks remain separate
conditions.

Compose methods, state controls, and event intent in one authored
program
The preceding examples established four separate boundaries: a method can be written in
complete text, a registry can retain its source and identity, a state invariant can reject a bad
book, and a selected event contract can retain the caller’s full intent. A usable program must
express those choices together. Otherwise a typed fixture may pass while the proposed language
has no way to write the same program or to show which semantic owner supplied a missing
field.
AuthoredCompanyText/1 closes this composition boundary with a bounded source format. The
program imports the opening book, report schemas, statement mapping and memory definition
by exact SHA-256 identities. It selects one BookStateInvariant/1 resource explicitly. These
imports are facts and checked rule resources; they do not silently generate methods or claim
that a small synthetic state is a complete disclosure history.
