5.3
Open-source components
The following survey uses official repository descriptions, licence files and selected source
interfaces archived on 2 October 2026. It is a source inspection, not an executed integration or
performance evaluation. The machine-readable tool ledger records retrieval paths and available
version metadata. Dependencies must be pinned when implementation begins; a branch name
observed during this survey is not a release requirement.
