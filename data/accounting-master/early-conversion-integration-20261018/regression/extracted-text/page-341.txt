If an earlier review had already accepted 2024 as the report year, the correction would require a
new reading and an explicit Supersede decision. Results depending on that reading would need
revalidation in the new evidence view; frozen earlier results would retain their original evidence.
This follows the review rules already stated above. Even after the visible title is resolved,
the cover year supplies no publication or availability timestamp for these particular bytes.
An as-of query must therefore retain the unresolved availability condition. This single-page
case motivates preservation and review behavior; it supplies no extraction-accuracy ranking or
general visibility test for other pages.
The inspected Arelle interfaces support native XBRL contexts, dimensions, transformations and
validation. Its internal object IDs do not replace stable source identity. The inspected Docling
source offers useful layout and table proposals, but its examined XBRL graph path does not
retain every required fact/context/unit/typed-dimension field. That path needs a preservation
sidecar or must report unsupported conversion for affected records. These are source audit
findings, not measured accuracy rankings of the tools.
A returned layout conversion can also conceal missing pages. At the pinned Docling implemen-
tation, the timeout branch assigns PARTIAL_SUCCESS when pages were expected, even if none
finished. The public convert_all interface permits that status through raises_on_error=True if
the remaining stages return normally. Thus absence of an exception cannot establish that a
three-page request produced any extracted content. The assembly code can restore missing page
numbers with empty page objects; counting those objects does not count successful processing
(Docling contributors, 2026). These are source-derived failure cases, not observed failures on
Apple’s filing.
The proposed exchange therefore keeps the original page inventory, requested range, successfully
processed pages, empty placeholders and structured errors separate. If only page two was
requested and processed, that is success on the declared subset; pages one and three remain
outside the conversion claim. If the three-page request times out before any page finishes,
all three remain unprocessed despite the partial-success status. Retain the source and the
unfinished pages for another attempt. A deadline is also distinct from stopped execution: the
inspected shutdown code waits for worker threads for a bounded time and can report that a
thread is still alive. Later execution must confirm termination within its isolated process before
treating the attempt as stopped (Docling contributors, 2026).
A requested processing stage may also remain unperformed. In the same Docling source,
automatic OCR selects among engines according to platform, installed packages, languages and
runtime availability. If it selects no engine and has recorded no language-specific rejection, it
logs a warning; the subsequent call returns the pages without OCR. Language-specific rejection
can instead produce an exception. Thus do_ocr=True records a request, not evidence that
text recognition occurred. The proposed adapter records the requested mode, selected engine
and model identity, and processing outcome for each page. A page that requires OCR but
did not receive it remains unprocessed, even if other stages produced layout regions (Docling
contributors, 2026).
Identifying the engine still leaves its model to be fixed. The inspected default layout preset
names Heron at revision main, while the TableFormer downloader names the model repository’s
v2.3.0 tag. Neither name supplies the hashes of the weights and preprocessing files actually
used. The proposed adapter binds those files, configurations and dependency versions before
use. Disabling remote inference services also does not disable model acquisition: the layout
helper downloads when no artifact directory is supplied. With a supplied directory it requires
the model’s subfolder, but finding that folder does not check its contents against the requested
revision. Local file verification and later isolated execution must therefore establish the intended
offline behavior; a source setting alone cannot do so (Docling contributors, 2026).
