13.13.4
Choosing the first import path
The first optional importer uses the retained Arelle source (Arelle contributors, 2026c) for native
XBRL, with the Apple 2024 instance as its concrete preparation case. Native facts already
carry contexts, units and occurrence relationships that a flattened table cannot reconstruct.
The selection therefore follows the preservation requirements established above. It selects a
source and an interface for the first implementation slice; the source commit is not an installed
release or a tested environment. The complete commit and body hashes are retained in the
source-selection manifest.
Use the previously inspected session lifecycle with no optional plugins or additional package
groups: request validation and its error-sensitive return, disable formula execution, and copy
facts and their contexts before closing the session. Each owning process admits one session at a
time. For this particular Apple archive, the recorded map has 27 resources and 3,551 reference
edges. Resolving those static references does not establish XBRL validation or closure of every
financial note.
The deterministic PDF comparator is the retained pdfplumber source, used for character and
page geometry on machine-generated documents. Its output remains a proposal to be checked
against the located page. A page that needs unadmitted OCR remains unresolved, with its
original bytes and manual inspection route preserved. Docling, TableFormer and OCR are
separate candidate paths. They do not become an automatic fallback that silently changes the
selected method, model terms or resource budget.
