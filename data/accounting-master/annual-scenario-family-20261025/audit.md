# Pre-execution skeptical audit — 25 October 2026

The earlier company-family engine accepts a different path schema. Adapting it
by copying only final balances would lose current tax vintages, recognition
history and provisional carries. The selected implementation instead delegates
each entire annual request, retaining the full result. Independent direct runs
are the comparator. The proposed query has no averaging or extrema arithmetic.

The most misleading possible pass would label a completed operation list an
annual report or drop a failed member before reporting. Tests therefore inspect
archived/current-prefix/unavailable distinctions, through-dates, assessment
status, zero budgets and failed members. Counts are bookkeeping only. Equal
financial results do not merge distinct member identities.

Defaults remain explicit convenience limits, not demonstrated scaling. An
unweighted finite authored list is not a reconstructed history set. The example
opening and scenarios are inherited synthetic controls with frozen provenance;
no information-cutoff, issuer, accounting-law or forecast admission follows.
The plan passes for bounded reference composition under these conditions.

Primary pass: exact full-result equality, retained members, correct joint report
selection and refusal of tampering. Broken dependency or baseline integrity
prevents recording. Implementation defects trigger repair. Expected scenario
refusals are evidence that failure is preserved, not a continuation veto.
