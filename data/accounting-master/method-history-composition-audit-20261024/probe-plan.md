# Exact composition probes

Use the first retained settlement from typed-monetary-effects/examples.py and
the recorded prerequisite-family fixture. Comparator: unchanged native return
transition and typed return transition on the same concrete state/event.

1. Establish original monetary/prerequisite/native agreement on the known case.
2. Reduce opening cash to 1 dollar and offset original equity by the opposite
amount, preserving total book balance and every component allocation. The
monetary/prerequisite family must remain feasible because it has no opening cash
input; native transition must reject funding after the refund/handling cash.
3. Attempt the retained sale before its returned lot exists, and after the
settlement creates it. Journal arithmetic alone cannot establish lot existence.
4. Set return quantity and matching cash facts to zero; monetary arithmetic may
balance but the exact strict original prerequisite must reject.
5. Compare event-dated method context with time-independent history book context.
The history explicitly rejects an embedded at key; an adapter must state the
event-time mapping and cannot silently drop arbitrary context keys.

These are deterministic negative/positive interface diagnostics. A successful
probe establishes the missing condition, not acceptance of any new composition.
Preserve original fixtures, commands, checks, source hashes and decisions. No
source eligibility, forecast comparison, solver default or numerical ranking.
