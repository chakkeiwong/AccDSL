# Nested semantic declarations and event membership

Explicit term-row declarations now check unique effective dates, predecessor
chains, the initial sentinel and issue/effective/due/book date relations.
Assessment declarations check unique dates, applicable historical terms,
overdue, nonnegative remaining amounts, supported origins and imported-event
identity. A generic projected-collection adapter binds term events and
explicitly filtered recorded assessments to the preserved seen-membership
engine. It introduces no alternative financial predicate evaluator.

Eighty-three complete runs over 22 retained states and adverse cases pass,
with 32 controls and 706 assertions. All 92 pinned dependency files remain
unchanged. The native validator independently accepts 22 states and rejects
14 targeted corruptions before candidate execution. Native financial callbacks
are disabled throughout candidate evaluation. These are 36 oracle cases,
not proof that every possible invalid state has been tested.

Complete declarations, typed rows, source lineage and preserved engine results
match independent construction. Empty populations still validate filters;
partial sources remain unresolved. Stale selection/order, wrong field/type,
unused sources and missing coverage refuse. The combined 256-row collection
boundary succeeds and 257 refuses without partial bound output.
