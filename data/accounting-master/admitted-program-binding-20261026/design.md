# One selected opening and execution contract

An explicit selection names the chart context, native-shaped input profile,
execution profile, exact role map, cost pointer, policy, full rule-set digest,
invariant digest and opening-template digest. It makes no inference that arbitrary
templates are equivalent. Selection identity is part of the returned result.

Every call binds selection/template/input/program content and both complete
input serialization orders. Evaluate opening admission first. A refusal returns
without execution. On admission, compare all shared facts, schemas, mapping and
memory definition; exact roles/cost/policy; actual rules/invariant against the
selected digest; and complete projected commands. Projection removes only the
assessment order and carry memory policy fields absent from the native input.
Event-input order is checked separately. The unchanged composer checks actual
assessment order and selected preserve-all-memory carry policy.

The execution object must equal the previously saved full composer result;
native substantive command requests/results remain independently compared in
the preserved predecessor tests. Added admission/binding records intentionally
differ from native wrappers. No reusable passing Boolean or caller certificate
can stand in for re-evaluation. Native functions are disabled for the entire
candidate, including opening. The selected chart contract remains finite and
does not establish a general equivalence proof for altered rule templates.
