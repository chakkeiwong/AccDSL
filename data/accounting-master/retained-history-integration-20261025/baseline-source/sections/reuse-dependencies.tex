\subsection{The source declarations constrain the first environment}
\label{sec:reuse-dependency-frontier}

The two selected source trees already impose a useful joint constraint.
At retained pdfplumber commit
\code{4c64b92d5caccd71c645e98e0fabb0c4dba7ff45}, its version file identifies
0.11.10. Its setup script reads requirements for pdfminer.six 20260107,
Pillow at least 12.2.0 and pypdfium2 at least 5.9.0
\citep{pdfplumberdependencies2026}. The selected Arelle tree
requires Pillow at least 10 but below 13. The shared declared interval is
therefore Pillow 12.2.0 or later, below 13. This is a necessary compatibility
condition; an actual resolved and tested environment has not yet been established.

The apparent Python minimum also changes when the dependency is considered.
pdfplumber's setup metadata says at least 3.8, while the pinned pdfminer release
requires at least 3.10. Arelle likewise requires at least 3.10. The combined
declarations therefore exclude Python 3.8 and 3.9 even before checking the
remaining packages and platform \citep{arellepinned2026,pdfminermetadata2026}.
These statements come from the retained
setup, requirement and release metadata; they do not recommend a latest release
or assert that every later Python version works.

pdfminer adds charset-normalizer and cryptography. Its optional image dependency
on Pillow is separate from pdfplumber's unconditional Pillow requirement.
No extra is selected by this proposal. Likewise, a package with no declared
Python dependency can still contain native libraries and third-party notices.
The inspected pypdfium2 metadata expressly distinguishes its own licences from
dependency licences \citep{pypdfiummetadata2026}. An empty Python dependency field cannot certify the
native runtime or its distribution terms.

Before admitting an environment, choose its actual platform and Python build,
resolve all selected direct and transitive versions, retain their distribution
hashes and notices, and test the exact source-preserving exchange. The source
declarations make that task concrete. They leave the installation, native
compatibility and component-specific terms as separate evidence obligations.
