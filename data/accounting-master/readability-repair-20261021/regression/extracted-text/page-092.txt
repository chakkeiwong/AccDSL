6.12
A query keeps its domain, endpoints and memory
The same displayed amount can arise from different input domains, and the same ending
cash can arise from different histories. A query therefore carries its domain, operation order,
endpoint status and requested state. The examples below make those fields concrete before the
implementation is asked to reuse a summary.
Real amounts, rounded outputs and a cent grid are different models
Return to the debt family in which nonnegative fixed-rate principal F and floating-rate principal
V satisfy
99.5 ≤F + V < 100.5,
4.5 ≤.05(F + V ) < 5.5.
The future interest query is I = .05F +.07V . The lower endpoint is attained at F = 99.5, V = 0,
giving I = 4.975. The upper endpoint is the supremum .07(100.5) = 7.035, but it is excluded
because the reported total is strictly below 100.5. The exact real image is [4.975, 7.035), with
an attained lower endpoint and an unattained upper endpoint. A solver result must carry both
facts; writing a closed interval would change the set. To establish that there are no gaps, hold
the total at 99.5 and vary V from zero to 99.5. Then I = 4.975 + .02V covers [4.975, 6.965].
The all-floating histories with totals from 99.5 up to, but excluding, 100.5 cover [6.965, 7.035).
Their union is the stated interval. Conversely, .05(F + V ) ≤I ≤.07(F + V ) excludes values
outside those bounds.
Now ask for a display rounded to cents, using nearest rounding with exact halfway values away
from zero. Every displayed value from 4.98 through 7.03 has a witness in the real family. The
lower raw endpoint displays as 4.98. The excluded raw supremum would display as 7.04, but
no admissible amount reaches it. Thus the rounded image has 206 values, 4.98–7.03. This is
an image of the real family, not evidence that the underlying amounts are cents. For any cent
amount x in the image with x ≤6.965, a witness is V = (x −4.975)/.02 and F = 99.5 −V .
Above 6.965 choose F = 0, V = x/.07. These formulas also show why enumerating cent displays
has not discretised the unknown principal.
A different model restricts F and V to integer cents before computing interest. Its maximum is
7.0343 at V = 100.49, and its rounded display still runs from 4.98 to 7.03. Equal displays do
not prove equal latent families: the real model admits values between 7.0343 and 7.035 that the
cent-grid model excludes. A stored result must therefore retain the model identity and input
quantum.
