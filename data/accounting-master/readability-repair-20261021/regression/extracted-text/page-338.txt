CHAPTER 13.
IMPLEMENTATION CONTRACTS
329
Relation
Key information and constraints
document
Hash, original path/URI, filing ID, entity, publication and
availability times, media type, revision links. Original
bytes are retained.
source_span
Document hash, page/element locator, bounding box,
text/table representation, extraction run ID.
observation
Context ID, value or missingness tag, precision domain,
source-span IDs, semantic-reading ID, review status.
context
Entity/perimeter, concept, basis, currency/unit, instant
or interval, dimensions and taxonomy version. Contexts
are immutable.
assertion_version
Logical assertion ID, payload hash, economic validity,
ingestion time, public availability, superseded version and
reason.
model_node
IR node ID, type, serialised payload, dependency IDs,
package/model version; no executable arbitrary text.
constraint
Expression, scope, source/assumption references,
supported solver fragment, applicable alternative
condition.
alternative
Parent model, added conditions, rationale, evidence,
coverage declaration and rejection history.
economic_event
Stable entity/book/branch/business-event key; versioned
event, contract/cohort, dates, quantities and
dependencies.
branch
Branch key and immutable definition reference, including
entity, book and required synthetic or real book mode.
branch_head
Branch owner, current state reference and generation;
updated only by the expected-head transaction.
posting_authorization
Exact basis, posting profile, method, authority, findings,
permission and historical view. A permission record alone
does not establish a committed event.
journal_batch
Committed balanced postings with event key, book/basis,
date, method and measurement references. Candidate
journals are separate; membership here requires the
complete accounting transaction.
economic_delta
Committed contractual and physical state change, bound
to the same basis and authorization as its journal.
committed_receipt
Unique stable event key, full request fingerprint, original
request, opening/closing state, journal and delta
references. Published atomically with those records and
the advanced head.
review_view
Immutable parent view, decisions and dependency
selection revisions; preserves historical interpretation.
dependency
Typed source and derived-record edges, including
candidate-set membership needed for transitive
invalidation.
search_checkpoint
Semantic manifest, partition, explored/unresolved regions,
frontier, used budget and result references, committed
together.
