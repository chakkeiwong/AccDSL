# Reconcile accepted scope and current source evidence

27 October 2026. C0/C3/C4 preparation; MC06/21/22/29/30/33/35.

The next two deliverables answer concrete questions. First, do the original
acquisition, bank and insurance acceptance provisions require the newest
unresolved conversion, recovery or issued/held extension, or do existing cases
already provide some required evidence? Second, where does each citation in
the protected candidate connect to retained technical reading and claim records?

Baselines are the exact original acceptance strings, the current 5.51-R1
sources, and immutable source/claim/snowball/omission ledgers. Read the actual
case and perform independent exact arithmetic where useful. A passing arithmetic
check establishes the stated numerical consequence only. It does not admit an
accounting treatment, prove every bank/cohort interface complete, or waive a
required company interaction. Preserve additional-operation limitations.

For literature, enumerate all citation occurrences in the candidate, parse
bibliography identities, preserve every discovered active ledger record with
its originating path and pointer, and bind matching IDs or manually checked
aliases. An exact citation key is a navigation link, not technical support.
Title/DOI similarity can nominate an alias but cannot establish edition
equivalence. Retain conflicting records; do not let later metadata overwrite
older technical scope. Verify local source hashes where stated. Citation
locations are not claim-level implication checks. Claims without exact current
locations remain visibly unmapped. Unmatched citations trigger targeted local
evidence search before concluding the source is unavailable or unread.

Skeptical audit: a generic source-support glob would count frozen copies as
new evidence and miss differently named authority/reading records. Inventory
the latter as unresolved routes, exclude known copies from the active ledger
set while recording them, and label the index a bounded consolidation. Preserve
every material limitation and existing technical anchor verbatim. The index
must never certify source support from a nonempty record or citation count.

Pass criteria: original clauses and input hashes unchanged; exact arithmetic
agrees with the stated cases; no blanket source blocker for an optional
extension; every current citation has a found-evidence route or a precise
remaining route; all inspected ledger records retain provenance and scope.
Hash mismatch, lost record, silently merged edition or changed case premise
vetoes the affected result and triggers repair. Counts are diagnostics only.
No new literature theorem, current legal/accounting advice, empirical result,
paid referral or whole-literature acceptance is asserted.

and citation-source-index.json/md in this execution directory.
