# Outcome query condition audit

Request identity and size: closed fields and parent canonical digest; strict
canonical rational threshold/coefficients; at most256 distinct account terms.
Prefix identity:1 or2, with exact original monetary type and date for every
selected account. No context stripping, invented scale conversion or code.

Parent conditions: unchanged complete compile_selection retains native opening,
fixed findings, first funding, shared carrying cost, lot chronology/identity,
minimum arms, sale funding, observations and every premise. Missing premise
halts; target obligations remain in the candidate-only answer. Unknown native
findings remain unresolved; false findings preserve unsupported status.

Predicate partition: equality equals its equal/less/greater partition and
inequalities have complementary strict/weak regions. Each complete parent
branch intersects each relevant region; no sampled state supplies the formula.
The solver must report one convex cell per region. A single global attempted
region count and remaining elapsed budget prevent multiplied budget allowances.

Positive evidence: a solver witness replays both original native events, then
Fraction arithmetic computes the requested same-prefix account sum and checks
both elementary region and query truth. Alternative satisfying witnesses are
valid even if the initial solver chose another point.

Negative evidence: full single-cell infeasibility and unsat recheck are required.
The verifier recomputes each supplied conflict against complete parent
constraints and the exact region. A smaller valid unsat core remains valid.
Unvisited, unsupported, timed-out or otherwise unresolved regions are not empty.

Classification: necessary/impossible require the appropriate complete empty
side and a witness on the other. Empty_family is distinct from necessity.
Two witnesses in opposite sides establish contingency even if other regions
are unvisited. Partial results retain proved possibility/refutation without
claiming global exhaustion. No target admission or numeric bounds follow.

Residual: elapsed limits govern solver calls and region scheduling; bounded
Python preparation/original replay are not hard-preempted. Runs close to the
deadline may change coverage. Current verification repeats the same budget and
compares semantic status; such boundary cases can need a larger explicit budget
for stable recorded evidence, never a stronger claim from a timeout.
