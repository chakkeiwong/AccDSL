10.12.2
Protection over time and imperfectly matching terms
Consider separately an option that protects an existing inventory holding for two equal periods.
Admit aligned initial time value 6 and a rational even allocation over those periods. Intrinsic-
value and inventory movements are zero in this illustration, isolating the protection cost. After
one period, supplied time value 2 gives an OCI loss of 4. Amortisation of 3 is reclassified to
expense, leaving the cost reserve at negative 1. After expiry, the final time-value loss of 2 and
second amortisation of 3 leave no reserve; cumulative expense is 6. Immediately expensing each
observed time-value fall would instead charge 4 and 2. That is a different timing policy. If the
intrinsic-value hedging relationship is discontinued after the first period, 6.5.15(c) requires the
remaining net reserve loss of 1 to enter earnings immediately. The remaining option asset of 2
is still an asset; discontinuation does not destroy it.
When critical terms differ, B6.5.32 requires an aligned option valuation using terms that perfectly
match the hedged item. The hypothetical option is a measurement input for the related cost,
not a replacement of the actual contract. Under B6.5.33(a) (Australian Accounting Standards
Board, 2022h, B6.5.32–33), if actual time value exceeds aligned time value at inception, base the
cost reserve on aligned changes and put the difference between actual and aligned changes in
profit or loss. For initial actual/aligned values 6/4 and later values 3/3, actual loss 3 separates
into OCI loss 1 and profit loss 2. At expiry, cumulative losses 6/4 leave OCI loss 4 and profit
loss 2, before the required transfer or reclassification.
If actual time value is initially lower, B6.5.33(b) limits the reserve by the lower cumulative
change of actual and aligned time value; the remainder of actual changes enters earnings. In a
same-direction decline example, initial values 2/3 become 1/2.5. Their cumulative losses are 1
and 0.5, so the cost reserve holds loss 0.5 and profit holds loss 0.5. At expiry, cumulative losses
are 2 and 3: the reserve loss becomes 2 and cumulative profit from the mismatch returns to zero.
The second period therefore records OCI loss 1.5 and a profit gain of 0.5, while actual value falls
1. Applying a fresh lower-of rule only to each period would lose this reversal. These numbers
test declining positive time values; they do not define a signed-value selector for every collar
or complex combination. Such cases must retain the source-defined alignment and valuation
analysis rather than infer it from this small example.
A zero-cost collar can have zero initial time value and nonzero intermediate time value. B6.5.31
still requires the related changes in OCI. A supplied movement from zero to 1.2 and back to
zero produces OCI gain 1.2 and loss 1.2; zero initial premium is not permission to omit both.
The terminal transaction cost adjustment and initial-cost amortisation are zero in that example.
10.12.3
The actual option and the hedged price need separate calculations
The time-value comparison also has to fit the risk being hedged. An actual option may have
a different exercise price from the price level the company has designated. Its payoff then
differs from the one-sided change in the hedged purchase. IFRS 9.B6.5.5 permits a hypothetical
derivative to measure that item but prohibits importing features that belong only to the actual
instrument. B6.5.32 similarly measures aligned time value using an option whose critical terms
match the item (European Commission, 2023a, IFRS 9.B6.5.5, B6.5.32–33). The following
complete transaction uses the retained historical EU compilation; it is a distinct conditional
example from the preceding AASB-profile illustrations.
