B.5
Example run request and response
The following request executes two named conditions under one scenario. It does not request
an aggregate probability distribution.
{
"model": "BorrowingExample@1",
"evidence_view": "synthetic-2025-exact",
"starting_state": "after-2025-close",
"horizon": {"start": "2026-01-01", "end_exclusive": "2027-01-01"},
"conditions": ["allFixed", "allFloating"],
"scenarios": ["rateShock"],
"mode": "conditional",
"weight_model": null,
"reports": ["balance_sheet", "income", "cash_flow", "equity", "journals"],
"package_lock": "demonstration-packages-v1"
}
The response contains two separately labelled results with interest expense 5 and 7, cash 90 and
88, debt 100 in both, and equity −10 and −12. A request for the parent symbolic family returns
the formula 7 −2α and, under exact linear bounds, [5, 7] before monetary quantisation. The
API rejects an unconditional mean request without a weight model. A user can instead request
an arbitrary clearly labelled representative case, which does not stand in for the feasible family.
