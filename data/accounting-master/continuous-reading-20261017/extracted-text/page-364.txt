Appendix A
Portable operation reference
These proposed versioned operations share the request and result envelope in Section 13.4.
Required inputs are explicit even when a list is empty. An expected head mentioned below refers
to the common envelope, never a second argument. The registry is a lookup reference after
the financial and transaction meanings have been explained in the body. These are specified
exchanges, not deployed endpoints.
A.1
The corporate exchange package
The Northstar example in Section 2.6 supplies a closed instance of CorporateJointHistory/1.
Its package is retained at data/accounting-master/corporate-portable-20261015/.
The files
record-schemas.json and portable-exchanges.json contain the closed record bodies, signature-
specific arguments, complete immutable records, required byte references, exact submitted
request bytes, results and the before/after store worlds. The accompanying semantic defini-
tion is docs/design/proposal/architecture/corporate-portable-20261015.md. These files specify
exchanges; generating or checking them invokes no product endpoint.
Each request uses the common envelope. Its arguments have exactly the two fields tag and
value: the tag equals the versioned operation name, and the value obeys that signature’s closed
schema. The profile and signature references bind the interpretation of those fields. Every
reference has a kind, schema and content digest. Its target must be present, with the correct
type and every required dependency; the submitted raw bytes are preserved even when decoding
or validation fails. A record’s dependency list contains its body references in canonical order.
Required source and schema blobs are checked separately by byte length and digest.
The eight source units retain the original inventory. Corrected interim and annual coverage
points to the complete historical reconstruction; the superseded original statement remains a
literal source with a separately typed revenue reading. The source-reference closure does not
imply that every source line has been admitted as accounting truth. A separate package variant
retains a missing incorporated debt agreement as an explicit obligation. The new qualitative
and rounding examples have their own authored source bytes.
