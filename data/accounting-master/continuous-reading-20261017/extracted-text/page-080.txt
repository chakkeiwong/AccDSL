Chapter 5
Architecture and reuse
5.1
One representation, several authoring methods
The architectural centre is a typed intermediate representation (IR), not a text parser. A
document extractor, a human editor, a Python library and the AccDSL compiler all create the
same records. This allows a modeller to begin with a reviewed structured file and later add
convenient notation. It also allows source extraction to improve without changing accounting
semantics.

Evidence storage and economic modelling must remain separate. If a company reports 100 of
borrowing, a model can assume two loans of 60 and 40 without creating a new reported fact
that the company disclosed those loans. The contract library consumes the assumed terms,
the accounting module consumes the resulting events, and the explanation graph records the
assumption at each affected result.
