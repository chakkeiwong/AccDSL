Full disposal and disposal with a retained 20% interest then start from separate copies of that
same immutable R state. Their branch identities prevent the second alternative from being
posted after the first. Each disposal proposal identifies its opening state, control change, source
books, cash consideration, retained fair value, rates and accounting method. Its permission to
post is conditional on this synthetic profile and exact proposal. It is not permission to post to
an actual company’s books.
In the retained-interest alternative, the parent’s receipt is 126.75. The group removes subsidiary
cash 156, producing investing cash 126.75 −156 = −29.25. The retained investment 42.25
is a separate noncash asset. Both disposal alternatives remove the entire NCI balance 31.2,
including its translation reserve 2.2. Only the parent’s reserve 10.4 is recycled into the disposal
gain. These are checks on the meaning of the journal, beyond the fact that its debits equal its
credits (European Commission, 2023a, IFRS 10.B98–99; IAS 21.48A–B; IAS 7.39–42).
The report reads one branch and one dependency view. In both alternatives, period profit is
58.8, of which 53.8 belongs to the parent and 5 to NCI. Period OCI is 2.2, attributable to NCI.
Ending NCI is nevertheless zero, because the disposal removes its accumulated balance. The
equity movement must therefore retain both its introduction and removal:
300 + 24 + 58.8 + 2.2 −31.2 = 353.8.
Reading only the closing NCI account would lose the subsidiary’s contribution while it was
controlled. Reading only final equity would also miss the difference between full-sale cash 353.8
and retained-interest cash 311.55 plus investment 42.25.
Publication follows the common accounting transaction rule. The request identifies the group
owner and expected opening revision; its business-event identity includes the branch. Before
publishing, an implementation must validate the source and currency bindings, posting au-
thorization, ordered journals and independently specified state changes. It then publishes the
closing state, journal, economic delta, receipt and new group head together. The parent and
subsidiary legal-book owners remain untouched.
An acknowledgement can be lost after that publication. Retrying the exact original request then
finds the existing receipt and has no second effect, even though its original opening revision
is now old. If publication never occurred, the same request can commit once. Changing the
request identifier, budget or expected head changes the fingerprint and cannot masquerade as
that retry. A newly proposed event with an outdated opening is rejected. The documentary
packet preserves both complete acknowledgement histories and an invalid partial-publication
example; later runtime tests must exercise those failures in the chosen storage system.
A corrected exchange-rate source creates a new evidence view.
It makes the old group’s
calculation unsuitable for a request using the corrected view, but does not overwrite the old
books or remove the old explanation. Unknown control or an unknown rate instead returns
the missing-input obligation, with no fabricated zero amount. The companion group-binding
