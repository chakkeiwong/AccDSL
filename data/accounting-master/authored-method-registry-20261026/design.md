# AuthoredMethodRegistry/1 and AuthoredMethodCall/1

This separate successor accepts entries with the original registry fields plus
an explicit transition_profile, exact authored source and source_sha256. A v2
entry additionally requires memory_definition. It checks source digest, lowers
the source and requires exact method and transition equality. It never renders
a typed method to invent source evidence. Method digest and source digest are
distinct. The same bounded method parser and native engines own semantics.

Every entry validates against the supplied current book, including unselected
entries. Account classes, event declarations, disjoint metadata bindings and
the direct-event clock retain the original checks. Static probes use fresh
unknown event inputs; predicates execute only in native propose. The selected
real event is checked exactly, then dispatched to the explicitly named engine.
Apply recomputes the entire proposal. No caller result or source admission is
trusted or inferred.

The registry is valid relative to a book. An entry reading a claim that has not
yet been created cannot be preloaded merely because an earlier command might
create it later. The sequential test therefore introduces that entry after the
sale, retaining exact registry identity at each step. This is an explicit
state-dependent boundary, not a whole-program compiler or dynamic scheduler.
Existing book/program profiles and hashes are unchanged.

The retained receivable lifecycle generator embeds claim identity, due date and
customer into each generated method. Its event still contains those extra fields;
the generic registry requires exact declared input population. Sequential
comparison therefore preserves the original event, explicitly projects its
unused inputs in a derived request, and records every removed value. It compares
complete state, journals and cash flows with the original native result, while
request/proposal equality is against the explicitly derived direct invocation.
This is a specialized-method comparison, not arbitrary dynamic claim dispatch.

Reference limits inherit 32 entries and one megabyte. Unknown engines or clocks
refuse; v2 without a memory definition refuses. Extra fields are rejected.
Both transitions remain provisional and preserve all native outcome meanings.
