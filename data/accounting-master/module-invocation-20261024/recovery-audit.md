manifest yet. Original frozen modules and unrelated changes remain untouched.
The original comparator is each native call, including its refusals.

The plan survives with a clarified assumption: native return validates source
and owner fields structurally, but changed well-formed packet hashes and owner
labels still produce proposals. Hash binding proves identity, not source
authenticity or ownership authority. Preserve this result and keep every
admission flag false; rejecting it in the wrapper would change the comparator.

and a changed lease scope unsupported. All four are now saved-case obligations.

The trusted local import environment is a convenience assumption, not an
isolation/security claim. All selected native implementations and schema files
are pinned on disk. The reference offers reusable invocation only, not shared
state, durable execution, arbitrary code loading, or issuer-state admission.
Exact native output preservation and refusal distinctions are pass criteria.
Timing and case counts are explanatory; they cannot promote accounting scope.
Unexpected comparator drift or changed protected inputs veto this package;
missing composition is the next planned repair, not a continuation veto.
