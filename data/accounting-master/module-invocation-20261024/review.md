# Bounded author review

The original-context baseline remains intact. The interface cannot select code
from user fields, request commit, drop module memory or relabel a native
refusal as success. Complete request/result replay catches forged cash, flows,
memory, status and admission flags. The native Henkel verifier checks actual
witness equations. Tests include malformed fields, stale hashes, raw input
digests, duplicate JSON keys, dependency/caller identity and input limits.

This is author inspection and deterministic testing, not independent review.
The caller assumes trusted local imports. Owner and source-label acceptance
by native return is retained and documented, not silently repaired in a
wrapper. Existing closed return and lease states remain incompatible.
The next work must establish actual state and transition semantics.
