Read the complete original lease derivation, authored four-step lifecycle,
component/type schemas, source policy and outer basis_effects checks. Original
source support is historical EU_IFRS for the retained synthetic period, not a
current compliance conclusion. No new standard interpretation is made here.

The outer verifier checks schema, exact numeric representation, owner/context,
view, source identity, period and method, opening component allocation and
journal balance. Low-level derive assumes those checks. Test non-Boolean flags
at the schema boundary rather than misreporting a truthy low-level value as an
accepted full exchange. The old shared-book adapter is return-specific. The
current native return registry lacks ROU and lease-liability; a callback cannot
insert these accounts into its closed registry.

Primary criteria: all original four steps agree with independently authored
values and exact hand arithmetic; heterogeneous rights retained; proposed company
joins preserve original owner/source and shared cash. An aggregate area/carrying
fraction is not a substitute for traced per-right amounts. Original component
accounting does not enforce company cash availability; audit that boundary and
state the extra no-overdraft funding premise before any native composition.

Assumptions remain inherited fixture premises: annual end payments, supplied
rates, traced allocation, supplied systematic depreciation, historical cash
classification and no intervening accrual. Early tests compare both original
rights and all original cash categories. Counts and balanced sums are diagnostic,
not sufficient acceptance. Protect15 files; no modification to frozen source,
authority or ledger. Failure triggers next boundary repair unless an input hash
changed. No forecast, actual fact admission or whole accounting compliance claim.
