# Explicit cumulative replacement of a provisional tax assessment

The selected model cumulative_replacement_no_credits_v1 is a hypothetical
choice, not a jurisdiction rule. It replaces the earlier provisional assessment
over the same original financial opening. It does not treat later activity as
an independent tax interval. Whole prior continuation and loss results remain
attached as superseded evidence.

Request ConditionalSharedTaxReassessment/1 contains the complete continuation
request and digest; a unique id; selected cumulative model; a later interval;
the exact original opening loss-state digest; a complete information map;
identified adjustment allocations; and explicit loss model/cap/usage/generation.
Recompute the continuation; incomplete requested execution remains unresolved
and keeps its full completed prefix. Do not fabricate a tax-free25-account book.

The later interval starts at the original financial opening, ends after the
previous assessment endpoint and no later than the native financial endpoint.
The last included day is exactly the preceding date. All recorded operations
must fit. The seven pretax accounts, all nondeferred balance-sheet accounts
including tax payable, and every original/retained lease right are explicit.
Required known declarations use the existing known/unknown provenance format.
Absent information stays unresolved. False required findings remain unsupported.
Jurisdiction and regime must match the original loss scope; all supplied fields
must be declared. Rates are nonnegative exact rationals with no arbitrary cap.

Count each native return adjustment once by exact event id and signed amount.
Other allocations require explicit assumption provenance. Per-account allocation
sums equal declarations. Four opening/closing right/account basis identities
hold. Cumulative taxable profit uses actual pretax financial balances, not the
after-tax profit or an artificial cash-restored counterfactual.

Recompute the close-day loss policy from the original opening loss inventory,
including original eligibility, expiry and past history. Never use the prior
provisional closing ledger as a fresh opening. The replacement creates one new
interval entry from that original opening. Provisional losses do not become
available for reuse in their own cumulative generation interval. A newly generated
replacement lot uses a fresh id distinct from provisional lots. Original results
remain available; this pure branch replacement does not revoke external commits.

Let C0 be already recorded cumulative current-tax expense, C1 the recomputed
total after explicit losses, and S actual tax payments. Require old payable
C0-S and new payable C1-S nonnegative. Post only delta=C1-C0: debit current-tax
expense, credit tax payable. A negative delta reverses expense/payable without
changing cash. If C1<S, return unsupported tax-receivable/refund route with full
calculation preserved; do not create a refund asset. No automatic payment,
credit, deferred recognition or annual authorisation is inferred.

The new state retains the exact continued book, changes only current tax,
payable, date and event identity, and records the new assessment endpoint/loss
state with superseded identities. All26 accounts and component memories remain.
Four financial statements/ties are recomputed from the unchanged original opening.
Apply recomputes the entire proposal. It is in-memory only, with no durable
commit, later ordinary-event/reassessment chain or financial-year carry claim.

Tests must independently verify positive/zero/loss totals, a downward charge
with unpaid balance, rejection after overpayment, exact original loss usage,
provisional-loss replacement, original loss-kernel equivalence, interval/basis/
allocation failures, unknown findings and whole-result tampering. Numerical
and engineering checks are criteria; counts are diagnostic. Audit passes for
this explicit profile only; wider law and annual completion remain unassessed.
