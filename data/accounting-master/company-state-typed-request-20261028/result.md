# Typed audit requests preserve native state and history outcomes

28 October 2026. T01/T03/C04; MC04/08/09/13/18/19/24/25/28/33/35.
Plan: docs/plans/company-state-typed-request-20261028.md.

Attempt-02 passes102 checks across12 baseline queries and18 adverse controls.
CompanyStateInspectionRequest/1 is a closed schema with explicit owner,
path/source digests, entity/book/currency, information use and typed queries.
The selected local owner is CompanyOperationPathDraft/1; no request selects
arbitrary code or an executable filename.

Annual reports equal native report_view results. Event prefixes preserve
year-qualified IDs and full claims/assets. Claim and asset histories retain
their creation origins and lifetime/prefix states. A missing supplied identity
is reported only as absent from the executed supplied prefix, while actual
existence remains unknown. Unknown openings return unresolved populations and
their obligations. Refused/unexecuted events never return successful snapshots.

Wrong owner, cross-profile joins and policy/public/manager information requests
are unsupported. Wrong context/digests, duplicate query IDs, missing or extra
fields, malformed dates and unknown query kinds are invalid. The full guarded
admission/native result remains attached on supported inspection. Source/actor
admission and complete-population/whole-company flags remain false.

Attempt-01 exposed a date-pattern escaping error in the new adapter and an
unguarded checker assumption. The original code, failure and repair are retained.
Explicit digit classes and a baseline-status check repair the authoring error;
the native executor and all protected prior results are unchanged.
