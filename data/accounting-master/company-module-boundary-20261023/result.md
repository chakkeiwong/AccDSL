unresolved, false findings unsupported, malformed or stale input invalid.

Northstar's current operation path is explicitly unsupported for this return
case. Seven capabilities are absent: operation syntax, return memory, required
findings, refund/recovery accounts, recovered-stock valuation, tax/report
classification and annual memory carry. The retained entity and 2024 dates
also differ. Portable bytes and references cannot close those gaps.

The boundary is intentionally finite: it accepts the exact protected event
and compatible state. It does not demonstrate general module substitution,
new ownership, the native return extension or accounting-source admission.
SectorCompany's existing report-only behavior is retained as a distinct
interface; this result does not turn its report into posting journals.
