## Reproduction and post-run challenge

Actual commands were prepare.py once, verify.py --record twice (first rejected
before recording), and verify.py for successful read-only replay, all through
python3 with the directory prefix shown in README.md. The successful verifier
used Python 3.11.15 and about 1.19 seconds. preparation.json and run-manifest.json
record exact command, interpreter, commit, times, input hashes and paths. Seeds
are inapplicable. The timing measures execution, not active author reading.

The strongest alternative explanation is agreement between authored examples
and their checker because both embody the same incomplete interpretation.
Fixed expected rationals/dates, direct XML comparisons and semantic corruption
tests reduce that risk but cannot eliminate it. An independent implementation,
adversarial native filings and taxonomy-aware validation could overturn the
proposed mapping. The weakest evidence is generalization beyond this small
XML subset; it remains explicitly unevaluated. Further checks of this same
fixture cannot substitute for that evidence.
