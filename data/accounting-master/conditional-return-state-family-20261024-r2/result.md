# Conditional native return-state families checked

24 October 2026. One complete retained native opening can now produce an exact
restricted family of settlement or whole-lot sale next states under authored
numeric event domains. Each feasible assignment replays both original native
transitions and compares complete state, journal and cash flows.

577 checks, 83 targeted regression methods, 13 retained cases and 517 protected
inputs pass. Eighteen new methods include low cash, strict quantity, event/lot
ordering, known/unknown findings, regenerated original date contexts, malformed
domains, missing premises, unsupported unknown products, branch/resource limits,
forged state and alternate witnesses. Counts overlap previous suites.

The known examples match the originals. Unknown return quantity is restricted
by the fixed cash facts, while alternative recoverable amounts produce distinct
valid lot carrying values. Opening cash of one dollar leaves the selected
monetary/prerequisite parent feasible but makes every native next-state branch
infeasible. The family inserts no financing. An already cash-negative opening
retains the original funding_failure instead. No actual source fact is inferred
from a hypothetical candidate assignment.
