# Source selector identity repair

27 October 2026. A pre-acceptance counterexample changed the fact raw XML while
retaining its supplied fact hash. The prototype accepted it because it compared
two hash strings without checking the bytes. This is an implementation failure,
not evidence against the tagged numerical reading. No accepted result exists
from that prototype. source_reading.py stays protected in source-inspection-01.

The selected successor binds every field of the inspected occurrence record
by an independently supplied complete-record hash and recomputes the raw-fragment
hash. The verifier also compares each retained raw fragment against the original
archive member. Changing metadata, fragment, order or a pinned selection must
refuse. Changing a selection remains an external review act; the selector does
not derive a new authority from changed input.
