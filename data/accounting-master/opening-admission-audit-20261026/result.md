# Remaining opening admission: audit result

26 October 2026. MC15/20/24/25/33/34; S2/S3/S4. Fifty-eight source-
anchored probes across both retained charts map ten obligation groups.
Nine protected files remain unchanged. This audit replaces no native check.

Native validate checks the closed envelope/profile, explicit policy and
provenance, typed book/memory, exact claim/clock schema, empty opening claims,
cursor equal to opening date, roles, unit-cost binding, state control, opening
report and command-list population. Role checks include completeness,
injectivity, account classes and cash identity. Unit cost must be a declared
leaf with exact price dimensions and a strictly positive rational value.
The opening report adds period-start, flow/temporary-balance and complete
statement-map obligations. A valid typed book alone is insufficient.

Six probes establish a separate timing fact: malformed future command kind,
unknown operation and unknown customer can pass opening validate and fail or
remain unresolved only during run. Consequently, opening admission does not
prove the complete future program valid. The new composer validates some
structural declarations earlier; its checked full-program correspondence must
not be generalized to every malformed-program failure prefix.

The native total-node limit can fire before its command-count limit. Separate
fixtures now isolate each. A zero-capacity map is rejected by typed memory;
capacity one with an empty opening is valid. The two incorrect initial probe
expectations were repaired without changing native code or policy. Policy
failure precedes cursor failure, which precedes role failure in the mapped
multifailure probes.
