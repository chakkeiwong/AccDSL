# Source-view interface and default audit

26 October 2026. MC01/02/03/11/12/13/24/25/26/28/33/34;
W01/02/03/04/12/16. Existing source mechanisms inspected before implementation.

FiniteVintageInference/1 and vintage-decision.select preserve immutable source
identities, supersedes ancestry, slot/information identity and maximal actor-
available heads. Their numerical path requires normalized priors and likelihoods.
Calling that path with a convenient uniform prior would change the present
unweighted robust-policy question. It is therefore unsuitable as a numerical
adapter. Reuse its canonical identities and ancestry convention, not posterior
calculation or expected-loss ranking.

CompanyInformationDraft/1 and PolicyInformationDraft/1 preserve authored,
published, ingested and accepted event observations with caller-supplied trust,
calendar-day intervals and separate public/system modes. The latter's _clocks
is reusable for the four-clock dependency check. Neither supplies actor-specific
access or economic effective time. A small explicit adapter must carry those
separately, alongside the admitted scenario interpretation; publication is not
personal access, and ingestion/review are not historical actor knowledge.

The older interval helper uses datetime microsecond precision. This selected
adapter permits canonical whole-second UTC instants only for those four clocks,
checked with the exact-information-time instant function before delegation.
Subsecond/day-valued requests are unsupported in this adapter, not silently
rounded. The existing exact-time engine supports richer instants separately;
a complete interval/exact-time composition is a future unit.

Material choices: the source registry is a closed caller-supplied dependency
scope (hypothesis, not complete company evidence); two named slots select world
family/receipt and observation scheme (reviewed finite baseline, not source
truth); replacement occurs only after actor access and system ingestion/review
and only when effective for the selected event (conditional bridge convention);
unknown relevant clocks produce unresolved output. Later known future clocks
exclude the revision at an earlier request without changing earlier selected
heads. Retraction leaves a required slot unresolved. Conflicting maximal heads
remain unresolved. No source bytes self-authenticate their availability.

The verified policy rows and saved complete sets are a frozen comparator. A
new source request must select exactly one of the existing eight problems;
unsupported model values remain unsupported. Recompute complete sets from the
selected saved rows through both existing formulations, bind the whole family
and observation identity, and compare with the saved full policy set. Do not
prune hidden contract types or add rates/rights to the actor signal.

Skeptical audit: pass only for a conditional dependency adapter. Semantic view
identity may ignore unrelated slots and provably future revisions, but every
request must rescan the current relevant registry; a cached digest alone cannot
detect a newly available correction. Identical output policies do not permit
reuse when source/interpretation identity changes. Changes in actor, decision,
system or effective cutoff invalidate the binding even when selected heads match.
Missing real access evidence blocks real-actor admission, not synthetic checks.

Evidence contract: compare independently stated cases for same/future/late/
unknown/conflicting/retracted revisions and changed actor/system/effective
cutoffs; complete policy sets must agree with both existing formulations and
frozen certified results. Hard vetoes: stale source reuse, future leakage,
unknown-to-known coercion, missing ancestry, forged trusted observations or lost
worlds. Counts/hashes/timing are explanatory; no forecast, probability, actual
control, actual availability, authenticity or durable cache is concluded.
